## 学术学位论文（本校评阅书优先）

### 选题

- [ ] 题目诚实、够收窄，能在现有条件下做完
- [ ] 问题来源真实，不是「没人做过」单独充当理由
- [ ] 英文题名准确点明研究对象与任务；若开头的泛称没有提供信息，可建议精简

### 创新点是否清楚、紧凑

- [ ] 每条写清承继、突破、价值、范围与证据，彼此可区分（「承继—突破—价值」为推荐字段，不是法定三要素）
- [ ] 主张紧凑，没有把宣传语（首次 / 填补空白 / 国际领先）或堆叠限定当成「严谨」
- [ ] 摘要、第1章、结论可对读
- [ ] 已按全文自洽六步检查（见 [argument-and-logic.md](../references/argument-and-logic.md)）：同一组对象、范围和条件；摘要未整段复制结论或引言，结论不是各章小结拼接（南大 2007 试行规定：除绪论外各章小结须写本章工作、特别是创新性成果，结论不是各段小结的重复，须标明文本年代及「仅供参考」；华科结论归纳有机联系的论点，各章须有严密逻辑论证关系，不是全国主线法律依据；西工大 / 华科摘要应突出创造性成果或新见解）；图表/假设/「首次、显著、极大地改进」未越出证据（通信学报英文文摘禁例只约束该刊，不要当成所有产品的法定词表）；北大 2014 年 4 月答辩指南「摘要不是引言的翻版」只约束该校流程，不要做成全国禁令；实验或仿真叙述了条件与过程（通信稳态随机性能估计沿用 Pawlikowski，不写 BER 事件数）；本人工作与他人工作已分开。不要把哈工大结论禁词或 2000 字、南大绪论字数、华科文献篇数、西工大第三人称摘要做成全国默认，也不要把主题句先行升为硬规则
- [ ] 位置符合学校规则（已打开的北大 2018/2019 及 2014 写作指南、2007 年《基本要求与书写格式》，以及清华 2025-03、东南、上交、北航、西工大、华科、南大 2007 试行规定、中科大 2026-10-29 模板：创造性工作主要在结论，引言未设创新点必备标题；不得用 2007 年文件恢复「北大必须第 1 章」；南大前置「前言」简述创新性成果，不是第 1 章标题，须标明 2007 年文本及「仅供参考」；中科大学术/专业博士另有前置「创新性说明」或「创新性及应用性说明」页（200–400 字），硕士须删除该页，不可用该页取代结论或摘要；哈工大博士创新点须在结论中分条，硕士结论可依实际情况考虑是否增加，不要写成硕士也必须分条；国科大结论应明确凝练出主要创新点，勿与西电 13806 未重核的「明确、凝练」是否栏混写；培养单位另有通知则执行该通知；其他：以模板为准）
- [ ] 未把某校评阅表栏数写成必须满足的国家法律（复旦 2025 自然科学学术博士评阅书是申请人三个编号栏且可另附页，不是强制至少三项，也不是评阅人必须列出三项或填「无」；西电自评 1–5 可续页同样只是表单设计）。审查时不要仅因条数不是 3 就列为主要问题

### 论证与证据（与主张类型相称）

- [ ] 相关工作按路线比较并给出缺口，不是摘要清单
- [ ] 各工作章回指总问题，不是独立小论文拼装
- [ ] 基线当代、配置公平；指标测的就是所主张的事
- [ ] 系统稿：负载与比较是否诚实，仿真未被写成实测
- [ ] 网络稳态随机性能估计事先声明精度、停止与暂态处理并报告区间。终止型实验说明初始条件和结束事件，并给出与轨迹或独立重复相符的分析。误码报告观测错误数及不确定度。
- [ ] 器件/电路：证据类型匹配主张；T-ED 类按现行 IFA 一般有至少部分物理验证或已收窄主张；未把仿真写成芯片实测；未把特刊的仿真禁令写成 TCAS 常设规则
- [ ] 机器学习部件：划分与泄漏、公平调参预算、测试集未不当复用或顺序过拟合、多种子分布及方差来源；未把「5 个种子 / p<0.05」当成普遍强制
- [ ] 工作量按主张与证据是否相称衡量，不以页数、图表数或实验组数计量
- [ ] 对主要工程设计，可根据图或文字追踪同一个输入、状态变化与作者负责的技术改动。架构、时序或实物图用标注说明重要差异。
- [ ] 对主要结果，逐章检查关键比较、反例、代价有可读的图表或可核的推导。对照原始记录复算一次关键读数，检查样本单位、差值方向及误差含义。
- [ ] 在最终栏宽复查最小图字、线型、灰度区分、面板和表头。若只有原稿或单张图，注明已查过的范围。[图表验收](../references/engineering-figures-tables.md)
- [ ] 未把事后假说写成事先假说；探索性分析已标明，主指标与停止 / 剔除规则可对读
- [ ] 缺失数据已说明处理方式，未用插值、生成式补全或邻组数字冒充观测
- [ ] 涉及明确物理量的器件或电路测量，已报告不确定度口径（n、标准不确定度与自由度，或 Type B 依据及所用覆盖因子）；未把通信仿真或机器学习测试分数改称按 GUM 计算的测量不确定度
- [ ] 缺实验仅在导致主张失去 warrant 时列为主要或阻断项。不要把未使用 research-to-report-and-briefing 或 Unbot 写成阻断项

### 规范性与表述

- [ ] 前置要素按学校模板及表 A.1 齐备（见 front-matter-checklist）；中科大稿件已按实际使用情况保留人工智能使用或未使用声明页
- [ ] **已先区分三类摘要窗口**（短摘要 / 详细摘要分册 / 留学生或外文撰写的详细中文摘要），未混用。摘要字数落在该校该文类窗口；无学校窗口时，中文论文按 300–1000 字核对；未把 5000 字套到中文论文，也未把复旦非中文撰写稿的 1000–3000 写成 5000；西电短摘要与详细摘要分册未混用；清华国际研究生中文摘要按 800–1000、一页以内核对；未把流传的国科大硕士/博士摘要区间当成规则；西工大短摘要无窗口时未补造
- [ ] 摘要人称符合该校或该刊（已打开的北大 2018/2019 写作指南全文无第一人称禁令，不得把「摘要不用第一人称」写在该指南名下，也不得用它收窄 6447；该校 2014 年 4 月答辩指南印刷页 38 限制「我们」等群体性称谓、一般用「本文」，只约束该校流程；通信学报避免「本文」「作者」；清华 2025-03 指南未见此项禁令，不得用来收窄 6447）
- [ ] 结论含核心观点、局限与后续，不是各章小结复述
- [ ] **已先读该校编号连接符与奇偶页规则**（图1-1 / 图1-3 与 图1.1 / 图 2.1 / 图1.2、公式连接符因校而异；西电每章奇数页起，西工大各部分首页奇数页，国科大大部奇数页起但章内不必，中科大仅第 1 章强制，北航不要求奇数页，复旦/南大章另起页），未统一改成一种
- [ ] 图题在图下、表题在表上；算法无国标专条，学位论文已按该校图/表或模板处理；IEEE / ACM 稿已分清各自算法体例（IEEE：figure + algorithmic/algorithmicx，不用 algorithm2e 浮动体；ACM：acmart 2.8，不得改边距）
- [ ] 边距：有学校数字则执行；未给时只核对 6.10 下限（天头/订口 ≥25 mm，地角/切口 ≥20 mm），未发明推荐边距。字体字号行距以模板为准（国标不规定这些）
- [ ] 发现同一来源两处数字或条款冲突时，已披露冲突，未代为选择（如通信学报 10 页与 12 页、西工大 7714 与 7713.1 交叉引用）
- [ ] 期刊摘要是否允许公式或图表，已按该刊指南或 7713.2—2022 核对，未用学位论文习惯改期刊稿
- [ ] 标点按文类分段：汉语部分按 GB/T 15834—2011；中科大模板 2.10 半角规定未扩至正文
- [ ] 学校手册若写 GB 3100—1993，未擅自改成年号；现行年号仍是 1993
- [ ] 参考文献体例正确（学校 / 7714 版本 / IEEE 等），无编造条目；学校规定的最低篇数或近五年比例已核（若有）
- [ ] 无诚信红旗（抄袭、篡改、伪造引用、未披露前作）

## 自然写作、衔接与保真终检（所有模式的文字输出）

具体判据见 [自然写作与文稿终检](../references/natural-writing-and-review.md)。

- [ ] 原句准确、自然时保留；已去除无信息增量的评价、机械复述与空泛预告，未按禁词、词频或句长配额改写，未添加口语或虚构经历
- [ ] 已按读者顺序连读，核对对象切换、首次出现的概念/基准、指代和因果/转折；上下文可解释的疑点已撤销，未靠连接词掩盖缺失前提
- [ ] 数字及变量归属、分母、基线、单位/幂次、公式/符号、否定与条件范围、证据类型、引文归属未因润色改变；中英对应事实一致
- [ ] 六类意见与三级严重度分开，文字问题可用原句定位，图表或缺失项可用具体对象或预期位置定位。每项均有依据、影响及改法，文风判断只针对文本。
- [ ] 仅审阅时保留正文；局部任务只改指定范围；审阅件与润色件如同时交付，已按同一原稿逐条核对处理状态
- [ ] 对最终版本独立读完本次范围（含保留内容及相关图表、公式、附录），从原材料追到成稿、从主张和意见追回材料；修改后关联位置已复查
- [ ] 已重开或回读实际交付物，按格式核关键版面/引用/批注锚点；未读、不可读或待核位置及受影响判断已说明，未将局部审阅称为全文通过
- [ ] 意见条数反映实质问题；确无问题时交零项结果与已核范围，不为凑数批注

- [ ] 已核对专业学位类别、申请路线和培养单位细则
- [ ] 专业硕士的应用研究型专题论文交代工程问题、分析及应用或验证。以实践成果申请时，所选成果、配套报告、展示和评鉴材料符合培养单位对该形式的要求。
- [ ] 专业博士按学位论文路线核工程难点、设计与方法、实施与结果及支撑材料，按实践成果路线核可展示实体、总结报告与证据。

- [ ] 本人贡献和团队成果的界线清楚。工程类硕士、博士及 0854 类别文件按适用对象分别核对，工作量评价有相应工程难度和验证材料支撑。
