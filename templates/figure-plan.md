# 图表规划与验收卡

工程整稿按重要主张使用；简单图可用几行记录。遵循[工程图表指南](../references/engineering-figures-tables.md)，不以图数、节点数或统一字号作为质量标准。

| 字段 | 本图/表的实际信息 |
|---|---|
| 稳定资产 ID / 所在章节 | |
| 对应 RQ / 主张 | |
| 读者必须完成的判断 | 动机、机制、总体关系、精确比较或边界等 |
| 表达形式及原因 | 框图、流程/时序、分布/趋势、精确表、原始影像等 |
| 数据或设计依据 | 实际运行、输入/输出、代码/规格/文献版本及位置；示意与观测分开 |
| 处理与统计口径 | 绘图脚本/配置；展示集合、统计集合、单位、分母及误差含义 |
| 可编辑源与导出文件 | 各自路径和文件身份；嵌入图像/不可编辑部分另记 |
| 目标最终尺寸与规则来源 | 实际单栏/跨栏宽度、图字/线条/色彩与图像要求；未知项待核 |
| 必须保留的内容 | 术语、标签、接口、箭头、用户人工改动及来源标识 |
| 正文引出句与解读位置 | 具体发现、对照条件、失败或边界 |
| 题注与显示编号 | 在最终稿核对子图、双语题注、续图/续表和目录 |

## 实际检查记录

| 检查 | 结果与实际范围 |
|---|---|
| 内容/数据 | 核过哪些图点、表项、接口或轨迹；未核部分 |
| 编辑结构 | 原生文字、形状、线、表、图像各自是否可编辑 |
| 导出 | 实际后端、命令/配置、产物身份和失败记录 |
| 最终版面 | 实际插入宽度；字体、上下标、线条、遮挡、裁切、灰度、表头/分页 |
| 跨处一致 | 源数据、题注、正文、章小结及摘要/结论对应是否一致 |
| 修改后失效 | 哪些输入/布局改变使旧检查需重做 |

“未执行”“无法读取”“已检查范围内未发现问题”和“发现问题”分别填写；源文件预览通过不能替代最终稿件的版面检查。
