# 关键词检查单

配合 [CY/T 173—2019](../references/cyt-173-2019.md) 与 [GB/T 7713.1—2025](../references/gbt-7713.1-2025.md) 5.2.9 使用。学校或刊物窗口覆盖本单的个数默认。

文稿：  学校或刊物：

- [ ] 个数落在约束窗口：学位论文无学校窗口时按 7713.1 / CY/T 173 的 **3–8**；清华 2025-03 为**不超过 5 个**、北大等为 **3–5**、浙大《编写规则》为 **4–8** 时执行学校窗口；期刊按该刊指南（例如已填写的 Computer Networks / Microelectronics Journal 为 **1–7**，《计算机学报》为 **5–7**）
- [ ] 中英文关键词对应（期刊论文按 CY/T 173 4.4 应有英文关键词；学位论文按 7713.1 与学校手册）
- [ ] 不是只根据题名选词；摘要、章节标题、结论中的主题已考虑（CY/T 173 5.2）
- [ ] 使用本领域规范术语；科学技术名词符合 CY/T 119 的习惯用法（不要把「电脑」当作「计算机」的正式关键词）
- [ ] 核心主题关键词在前，限定或非核心因素在后
- [ ] 中文关键词之间用分号隔开，最后一个关键词后不加标点（学校模板若另有分隔符，执行模板）
- [ ] 作品名称已加书名号，特定含义用语已加引号（如需要）
- [ ] 关键词确实出现在论文的专业表述中，没有为凑数而加入正文未讨论的词
