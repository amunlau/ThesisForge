# GB/T 7714—2025 计算机相关著录示例

示例取自首都经济贸易大学馆藏排印本（校名水印的官方等价文本，非市场监管总局开放下载）中条款 8.11.3、8.14、8.15 及附录 B.10 的完整条目，可略作排版压缩，不另行编造题名、日期、DOI 或路径。规则说明见 [gbt-7714-2025.md](../references/gbt-7714-2025.md)。学校若仍用 2015、自有样式，或未写明 7714 年份，以学校为准，不要把本页示例悄悄套到尚未切换的学校稿上。

## 预印本 `[PP/OL]`

格式：`主要责任者. 题名: 其他题名信息[文献类型标识/文献载体标识]. 版本. 出版平台 (创建或修改日期)[引用日期]. 获取和访问路径. 永久标识符.`

```
Jenkins S D, Ruostekoski J. Controlled manipulation of light by cooperative response of atoms in an optical lattice[PP/OL]. V2. (2012-03-18) [2020-06-24]. https://doi.org/10.48550/arXiv.1112.6136.
```

同一条款下，PSSXiv 与 ChinaXiv 示例给出了出版平台名称并另著 **CSTR**；本条 arXiv 示例以 DOI 为获取路径，排印本未再单列平台名。要点：类型用 PP，给出日期对（创建或修改日期 + 引用日期），PID 已包含在 URL 中时不必再单独重复（7.9.1）。

## 数据集 `[DS/OL]`

格式：`主要责任者. 题名: 其他题名信息[文献类型标识/文献载体标识]. 版本. 发布平台 (发布或修改日期)[引用日期]. 获取和访问路径. 永久标识符.`

```
IHME. Global burden of disease study 2019 (GBD 2019) data resources[DS/OL]. Global Health Data Exchange (2021) [2025-07-15]. https://ghdx.healthdata.org/gbd-2019.
```

标准中另有：带版本（如 V1.0）、中文数据中心与日期对、URL 本身含 **CSTR** 的示例；以及 URL 之后另著 DOI 的示例。引用日期必备。需要完整中文条目时对照排印本原文，不要补造路径。

## 同一 Zotero 条的两种类型代码（标准自身不一致，并列照录）

条款 **8.11.3** 网页示例 [5]（该条款标题是「网页」，不是「计算机程序」）：

```
Zotero. [Zotero download][CP/OL]. [2024-04-08]. https://www.zotero.org/download/.
```

附录 **B.10** 网站、网页示例 [13]：

```
Zotero. [Zotero download][EB/OL]. [2024-04-08]. https://www.zotero.org/download/.
```

两条都来自同一份排印本，不要把其中一条改正成另一条。B.10 提取文本中的 `down-load` 是换行连字符，不是第二条官方 URL。在勘误下达之前，不以其中一种写法为「该条的」官方规则。**综合意见（非官方裁定）：** 引用程序本身用 `[CP/OL]`，引用介绍它的网页用 `[EB/OL]`。

## 著录时不要忽略的几点

- 拉丁文姓氏仅首字母大写：`Jenkins S D` 或 `Einstein A`，不是 `JENKINS S D`（7.1.1）。汉语拼音姓名的名宜用全称（如 `Li Jiangning`）。
- 著作方式相同的责任者不超过 3 个时应全部照录；超过 3 个时**可**著录前 3 个加「, 等」或相应词（7.1.2，「可」不是「应」）。
- 获取路径已含 DOI/URN 等 PID 时，不要在条末再重复同一个标识符（7.9.1）。路径不含 PID 时再按来源著录 DOI、CSTR 或 URN（7.9.2）。
- 预印本、数据集、网站的引用日期不要省。
- 会议论文、电子版学位论文、online-first 期刊文的格式见 [gbt-7714-2025.md](../references/gbt-7714-2025.md)，不要把本页未给出的条目补写完整后冒充标准原文。
