# 学位论文构成要素清单（据 GB/T 7713.1—2025 表 A.1）

先核对学校采用的标准版本和模板。下表按 GB/T 7713.1—2025 的规范性附录 A 标注必备性，学校未规定时可作默认参考。封面措辞、声明页原文、字体字号一律套模板，不要按本表发明排版。学校未给边距时，只按 7713.1 6.10 下限核对（天头/订口 ≥25 mm，地角/切口 ≥20 mm），不要发明推荐边距。条款说明见 [gbt-7713.1-2025.md](../references/gbt-7713.1-2025.md)；期刊轨道见 [gbt-7713.2-2022.md](../references/gbt-7713.2-2022.md)；学校连接符、奇偶页与声明页见 [school-overlays.md](../references/school-overlays.md)、[format-and-citations.md](../references/format-and-citations.md)。

## 叠加层与形式检查备忘

- [ ] 已对照学校手册的摘要字数、关键词个数、创新点位置；**已先区分短摘要 / 详细摘要分册 / 留学生详细中文摘要**，未把不同窗口混用
- [ ] **已先读该校编号连接符与奇偶页规则**（图1-1 / 图1-3 与 图1.1 / 图 2.1 / 图1.2、公式 (3-32) 与句点分章并存；西电每章奇数页起，西工大各部分首页为另页奇数页，国科大大部奇数页起但章内不必，中科大仅第 1 章强制奇数页，北航章另起页但不要求奇数页，复旦/南大章另起页、复旦未写必须奇数页）。不要统一改成一种连接符
- [ ] 图题在图下、表题在表上；续表按国标「（续）」或该校等价用语并重复表头；算法无国标专条，学位论文按该校图/表或模板处理；IEEE 稿放进 figure（algorithmic / algorithmicx，不用 algorithm2e 浮动体），ACM 稿以 acmart 2.8 为准且不得改边距
- [ ] 边距：有学校数字则执行；未给时只核对 6.10 下限（天头/订口 ≥25 mm，地角/切口 ≥20 mm），不发明推荐边距。字体字号行距以模板为准（国标不规定这些）
- [ ] 量和单位按 7713.1 4.5 指向的 GB 3100 家族。GB 3100 现行年号仍为 1993；修订稿建议 2028-01-01 实施。学校仍写 1993 年号则按叠加层执行，不得擅改。IEEE 稿不要与这一套混改
- [ ] 学校若仍引用已废止的 7713 / 7714 旧版，按校规执行，并记下与 2025 的差异（西电 2025-01 模板仍写 7714-2005；中科大 2026-10-29 已改引 7714-2025；复旦规范写「最新版」7714 且同页提供 2025 文件；西工大已依据 7713.1—2025，但参考文献条款内部不一致，须披露冲突、不代为改掉）
- [ ] 发现同一来源两处数字或条款冲突时，已披露冲突，未代为选择
- [ ] 标点按文类分段：汉语部分（含中外混合排版中的汉语）按 GB/T 15834—2011；中科大模板 2.10 半角规定只约束参考文献，正文仍按 3.3 / 15834
- [ ] 西工大稿件若含人工智能生成合成内容，已按指南做标识。中科大稿件已按实际使用情况保留人工智能使用或未使用声明页，并删去未选用的另一页
- [ ] 专业学位博士若适用学位办〔2024〕18号，核对学位论文或实践成果路线，按本校规定核对前置材料，见 [moe-professional-doctorate-2024.md](../references/moe-professional-doctorate-2024.md)
