## 结构（按刊物删改）

1. Introduction：研究情境、问题及本文贡献。按稿型决定是否单列贡献或概述结构。
2. Related work：按路线，位置（引言内 / 独立节 / 方法之后）
3. Method / System / Model
4. 实证稿写实验与分析，理论稿写推导或证明，综述写材料范围、综合方法与发现。
5. Discussion
6. Conclusion
7. Appendix / Data availability / Ethics
