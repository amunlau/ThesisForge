# 中文科技写作衔接能力改进与行为验证

日期：2026-11-20。本次改进针对工作目录中的 ThesisForge，依据用户提供的段落组织需求，不代表重新审核所有学校规范或发布新版本。

本文保留写作能力专项阶段的实际验证；后续工具修正与当前提交前测试见[提交前复核](precommit-review-2026-11-20.md)，不要将下文的历史计数视为最新工具测试总数。

## 范围与规则落点

已通读用户的 418 行需求，检查 ThesisForge 入口、写作/论证/权限/审查/文档/回复参考及既有验证记录；另由只读审计者核对本机 Unbot 的入口、篇章衔接、中英文表达、编辑模式、审查分类与已有夹具。本次以用户开头明确指定的 **ThesisForge** 为修改对象：Unbot 用于一致性比对，未修改其安装副本，也未覆盖已安装的 ThesisForge。

纠正的主要冲突：

- “只有无法合理补链才列意见”会漏掉可推知但反复回读的障碍，已替换为统一的三种处理判断。这不是新的问题分类或严重度体系。
- “一段一个主要关系”容易把同一段任务中的条件、比较、证据拆散，已改为主要任务；不按主语、时间、指标或句长分段。
- “调整章节与段落顺序”“直接移动信息”原先缺少权限限制，现按委托执行。自然语言授权已足够，不新增确认门槛。
- “补齐因果环节”可能被理解为补造机制，现仅恢复材料已有关系，缺口留为具体待核。
- 不将流畅度等同于事实正确；移动数字时保护对象、条件、状态与引用，段末引文组支持范围未明时不逐篇重分。
- 收尾只读复审还指出“写作修订不触发新实验”可能被误读为禁止已授权补实验，已收窄为“不能仅因衔接优化而启动新实验，已授权的补实验仍按实验流程执行”。这一范围澄清发生在行为演练后；未因此重跑全部演练。

## 实际行为验证

原始材料：[20 项回归输入](cohesion-regression-inputs.json)、[5 项未见输入](cohesion-holdout-inputs.json)。实际答复完整保存在[输出归档](cohesion-forward-results.md)，仅统一换行，并在提交前把 H03 的本机技能路径转为仓库相对链接，没有把答复修饰成预期答案。

三个未继承本轮对话的执行者分别处理 R01—R14、R15—R20、H01—H05，只收到技能入口、相应原始请求、材料和允许的输出路径，未收到预期答案或缺陷清单。每项按独立用户任务执行；同批任务共享执行者上下文，并非 25 次完全隔离的模型运行。主执行者逐项核读实际输出，按对象、关系、保真、权限和误改判断，未使用关键词命中或批注数量评分。

H01—H05 由未读取 ThesisForge 规则的另一执行者编写，正文未用于本轮规则编写；输入生成后未修改。其预期判断单独保存于协作记录，未发给执行者。H03 的验收按实际“仅润色”权限校准：发现机制断言超出证据，应在正文外说明并提供备选修订，不能把擅自改变结论强度当作通过条件。

| 场景 | 实际输出与复核结果 |
| --- | --- |
| R01，多对象后的“其” | 列出系统/A/B 候选，未按最近名词或优先级线索擅定对象；正文未改 |
| R02、R03，自然回指与省略 | 接收队列的“其”和称量操作的省略均保留；语言审阅未扩成实验真实性审计 |
| R04、R05，多主体流程与时间阶段 | 主机—设备—主机保持同一流程段，三个试验阶段保持一段；数值和前提保留 |
| R06，多对象、多指标比较 | 面积和功耗共同用于工程取舍，未强拆，也未把“分别”判成不清楚 |

| R10，一段式摘要 | 目的、方法、结果与边界仍为一段；保留拓扑、基线、注入率、周期数及尚未验证范围 |
| R11，省略导致执行者不明 | 分别指出压缩、入库执行者无法确定，没有自行指定网关 |
| R12，源码换行 | 将 LaTeX/Markdown 单换行识别为折行，保留真实空行段落及标签；未声称编译或版面通过 |
| R13，可恢复但回读负担明显 | 只将第三段“其”明确为缓存管理器，保留 4 ms 和“仅清理已确认”；未输出前两段替换稿 |
| R14，自然准确的段落 | 零项修改意见，保留条件、隐含衔接和非普遍最优的取舍边界 |
| R15，重建材料的只审阅 | 同时发现产品层级不明、搭配问题及合作规划偏题；给出整句目的位置，不改正文；组引支持范围待核 |
| R16，同材料的普通润色 | 保留标题与段落边界；修正场景/需求表述，产品层级仍未擅定；跨节移动仅作为建议 |
| R17，同材料的结构整理 | 将合作规划整体移入已有对应小节，保留 10,000 颗、非已交付及 [9]；场景/约束/要求同段，未重分 [4,7,8] |
| R18，起草计划 | 保持拟比较、尚未运行和结果未知，不补造仿真收益 |
| R19，句间关系 | 识别固件/信道同时变化不能单独归因，以及体积与丢包率不构成“相反”；未将数值正确误当论证正确 |
| R20，从材料写结果 | 区分本研究仿真、另一拓扑文献观察、机制未验证及满足预算的设计取舍 |
| H01，跨多个活跃对象回接 | 明确“偏置伺服单元”，保留局部清楚的“前者/后者/它”，未错配阈值与模块 |
| H02，相邻自然段 | 两段原样保留，分别完成定位效果和工程时延取舍，未强合段或补强因果 |
| H03，证据角色与润色权限 | 修复第三段取舍的回接；指出跨材料文献不能证明本器件机制，原断言保留并另给替换建议，未暗改结论 |
| H04，审稿回复 | 按记录分开已完成的离线重放、计划中的高温测试与厂商固件修复；未把厂商工作写成作者工作或已验证结果 |
| H05，摘要和图注 | 摘要补全方法名与温度范围；图注按可见面板补限定，未重复塞入所有图轴信息；统计量与长期漂移边界保留 |

这 25 项的本次实际输出均满足所核核心行为，未发现需要据此继续修改规则的失败。结论是小规模、单轮的行为检查，不能换算成准确率、跨模型稳定性或整篇论文无错保证。
