# 五套参考技能的整合记录

日期：2026-11-18。实施依据是用户明确指示：需要作者决断的设置采用评估中的建议，不建议的保持不引入，其余按建议改进。实施前评估保存在 [综合报告](../参考skills/对照分析/00-综合评估与决策清单.md)及五份详表；它们是历史基线，原文中的“尚未修改”描述的是评估阶段。

后续专家/审稿回复专项的新增能力与最终验收见[该阶段记录](reviewer-response-integration.md)。本文件的测试计数及指纹描述本阶段完成时的版本，保留为历史记录。

## 实际变化

- **工程研究与结论：** 贡献类型匹配证据，模块输入/处理/输出及接口逐边核对，训练与推理分离；展示样本与统计样本分开，结论回到研究问题、比较条件、失败和适用范围。新增 benchmark/数据集专项、图稿计划，保留真实实验运行器与 NoC 复跑。
- **保真写修：** 保护条件、否定、比较、数量归属和结论强度；区分表达、结构与主张修改。多文件稿件扫描提供真实位置、范围和疑点，不能冒充语义证明。返修记录对齐原始意见、实际变更及最终页码，投稿声明只取真实事实。
- **文档后端：** 跨平台只读 DOCX 审计，动态样式继承、域、分节、表格/文本框与修订覆盖；可选 Windows Word 工作副本导出；可选 LaTeX 工作副本构建，缺工具、失败、陈旧产物和未解引用分别处理。
- **证据与制图：** 一份轻量项目记录；文件依赖及主张证据固定版本，变化后旧检查失效。精确局部补丁保护原文件；本地题录保留来源、重复和拒绝项；Mermaid/draw.io 适配器保留图源、命令及真实导出状态，最终图义与版面另验收。
- **安装与来源：** 安装器携带新增 JSON 模板和 PowerShell 后端，两宿主复制同一套资源。第三方源码快照继续独立存放，不进入安装包。新增代码与规则独立撰写，来源在 NOTICE 中列出，主许可证保持不变。

逐项去向见 [286 项吸收对照](reference-integration-items.md)。其中 203 项是建议吸收或补强，35 项局部决策合并为下面 23 组，48 项不建议原样吸收的规则没有导入。计数包含重复原则及既有能力，**不是 238 个全新功能，也不是 286 项行为已经全部自动测试**。表中分别标明规则、工具、既有能力和可选扩展边界。

独立代码复核还修复了证据重新登记使旧主张恢复支持、图形超时遗留子进程、BibTeX 注释伪键、逗号标签、内联书目、千位数值、条件分支和非 `.tex` 子文件等问题，均有对应行为回归。测试计数包含原有测试，不能当作新增功能数量。

已知边界：没有真实 TeX 环境构建验证；图形适配器的流程测试使用合成 CLI，不代表真实 Mermaid/draw.io 整套兼容性；Word 合成试件实测不代表学校长论文合规。新工具不提供通用学校样式归一化、引用语义认证、作者身份检测或自动录用判断。工具覆盖之外仍由实际任务中的读取、实验、复算与视觉检查完成。
