# 第二轮调研　工程研究的图与表

2026-11-11。以“按图能否追到技术决策或原始观测、缩到目标版芯能否读清”为问题，独立检索中文工程期刊、工程写作教学、出版社制图、图表研究、数据可视化博客、架构与时序绘图工具。查询词包括“通信学报 插图 矢量 三线表”“科技论文 函数图 编辑实践”“科研图像处理 科学网”“IEEE final size graphics fonts”“paired data figures”“engineering figure design”“architecture diagram notation”“accessible tables”。以下 52 条为对材料的释义与工程迁移。同一结论在不同出版体系下的差异保留在表中。在线指南在实际投稿时重新核对。

## 进入技能的决定

实施时优先处理容易改变技术判断的项目。创新主张找不到对应证据图、时序不能区分规格与实测、汇总掩盖配对、跨栏缩印令标注不可读，均应在成稿前解决。刊物实例用来演示如何查尺寸和字号；页均图数、配色、三线表和字形设置按题目及模板决定。为同一组数据重复画图、把网页悬浮提示迁入静态论文、工程图套用幻灯片字体，这三类做法均未进入通用要求。

额外核对了过程图与架构图的区别。ASQ 的 Basic Procedure 和 Commonly Used Symbols 要求确定流程起止、按顺序连接操作、由判定题的不同答案标明不同去向，并建议实际走一遍。本轮将这一检查用于实现流程的正常分支与例外分支；它补充 V08 的箭头语义，未另计建议条数。[ASQ 流程图教程](https://asq.org/quality-resources/flowchart)
