# GB/T 7714—2025 参考文献著录要点

信息与文献 参考文献著录规则。发布 2025-12-02，实施 2026-07-01，完全替代 GB/T 7714—2015。本节只收录已与排印本交叉核对、且对计算机/通信/器件学位论文最有用的规则。完整示例见 [citation-examples-7714-2025.md](../templates/citation-examples-7714-2025.md)。学校或目标期刊另有体例时，执行该体例，不要用本文件去「纠正」IEEE/ACM 稿，也不要在学校仍用旧版或未写明年份时悄悄改成 2025 示例。

**文本来源与限度：** 条款与示例依据首都经济贸易大学馆藏排印本（https://rem.cueb.edu.cn/docs/2026-04/ab13582039564d9090a722f17cfcbf2e.pdf，48 页，中国标准出版社购得本，带「首都经济贸易大学 专用」水印）。这是官方等价排印文本，**不是**市场监管总局 / openstd 的开放下载。openstd 与 SAMR 记录确认本标准非等效采用 ISO 690:2021，并因版权**不提供在线全文**；大学馆藏排印本仍是工作文本。华侨大学研究生院 2026-03-01 公示的 7714—2025 附件、以及清华大学图书馆托管的 7714 文件，第4轮均已下载但为图像 PDF，抽不出正文，不能替代首经贸排印本重核条款。第三方评论文章里超出条款表的额外说法（例如「非网络类型取消引用日期」「学位论文首次必须著录页码」）视为**未核实**，不写成硬规则。

## 对计算机类论文特别重要的通则

- **新类型与术语（第3章、前言、表 A.1）：** 数据集（3.6）；永久标识符 PID（3.10，含 DOI、URN 等）；预印本（3.11：「尚未通过同行评审但仍可广泛使用的文稿」）；类型代码 **PP**；载体代码 **MM**（缩微品）。表 A.1 仍保留：**CP** = 计算机程序，**DB** = 数据库，**DS** = 数据集，**PP** = 预印本，**EB** = **网站、网页**（不再是「电子公告」）。
- **没有「计算机程序」专章。** 第8章文献类型为：8.1 通用要求；8.2 图书；8.3 图书中的析出文献；8.4 连续出版物；8.5 连续出版物中的析出文献；8.6 会议录；8.7 学位论文；8.8 报告；8.9 标准；8.10 专利；**8.11 网站、网页**；8.12 档案；8.13 地图；8.14 数据集；8.15 预印本。附录 B.10 同样是「网站、网页」。计算机程序与数据库只有表 A.1 的类型代码，没有单独的 8.x 章。不要再把 8.11.3 写成「软件著录条款」。
- **永久标识符（7.9）：** 7.9.1 获取路径中**已经包含**该 PID 时，可不重复著录（例如 URL 已内嵌 DOI 或本身即 URN）。7.9.2 路径中不含 PID 时，可按原文如实著录（DOI 示例；8.7 中有使用 **CSTR** 的学位论文示例）。DOI、URN、CSTR 均在范围内。
- **个人责任者（7.1.1）：** 姓在前、名在后。用西文著录时：「姓应全部著录，首字母应大写，名可缩写为首字母，如用首字母无法识别该人名时，可著录全名」。用汉语拼音著录时：「姓应全部著录，首字母应大写，**名宜用全称**」。示例包括 `Einstein A`（原题 Albert Einstein）和 `Li Jiangning`。**这不是姓氏全大写规则**，不要再写成 `EINSTEIN A`。5.6 还规定：著录西文文献时，大写字母的使用应符合信息资源本身文种的习惯用法。
- **责任者数量（7.1.2）：** 「著作方式相同的责任者不超过 3 个时，应全部照录。超过 3 个时，**可**著录前 3 个责任者，其后加『, 等』或与之相应的词。」这里的「可」是许可，不是「应」。
- **电子资源日期（7.6）：** 创建/发布或修改日期以及引用日期，采用 `YYYY-MM-DD`。
- **无页码而有文章编号（7.7）：** 把文章编号著录在页码位置。
- **引用日期：** 对网站/网页、数据集、预印本为**必备**（条款表 10、11、14、15）。不要把未核实的「其他类型一律取消引用日期」写成规则。
- 电子资源规则不再单独成章，而是并入各文献类型，因而 `[J/OL]`、`[DS/OL]`、`[PP/OL]`、`[D/OL]`、`[C/OL]` 各有自己的必备/可选要素表。

## 数据集（8.14）`[DS/OL]`

格式：

`主要责任者. 题名: 其他题名信息[文献类型标识/文献载体标识]. 版本. 发布平台 (发布或修改日期)[引用日期]. 获取和访问路径. 永久标识符.`

引用日期对数据集为必备（表 14）。发布平台对电子资源为可选。PID 若已出现在 URL 中则不必重复。标准中有带版本号与 CSTR 的数据中心示例，以及 URL 之后另著 DOI 的示例。

## 预印本（8.15）`[PP/OL]`

格式：

`主要责任者. 题名: 其他题名信息[文献类型标识/文献载体标识]. 版本. 出版平台 (创建或修改日期)[引用日期]. 获取和访问路径. 永久标识符.`

标准示例使用 `[PP/OL]`，覆盖 PSSXiv、带 CSTR 的 ChinaXiv，以及 arXiv（如 `https://doi.org/10.48550/arXiv.1112.6136`）。不要再把这类文献勉强归入 `[EB/OL]` 或 `[J/OL]`。引用日期必备。

## 网站、网页与计算机程序（8.11 / 表 A.1；不要把两者写成同一专章）

8.11 与 B.10 都是「网站、网页」。8.11.3 的标题是「网页」。网页示例 [1]–[4] 使用 `[EB/OL]`。

**标准自身尚未解决的内部不一致（排印本已核对，不是转写错误）：** 条款 **8.11.3** 示例 [5] 把同一条 Zotero 下载页写成 `[CP/OL]`；附录 **B.10** 示例 [13] 写成 `[EB/OL]`。B.10 提取文本中的 URL 有换行连字符 `down-load`，不要把它当成另一条官方地址，官方路径仍是 `https://www.zotero.org/download/`。在市场监管总局开放排印本或勘误下达之前，**不要把其中一条写成「该条的」官方规则，也不要悄悄把一条改正成另一条。**

**综合意见（标明为综合，不是隐藏的官方裁定）：** 被引对象是程序本身时，用 `[CP/OL]`；被引对象是介绍该程序的网页时，用 `[EB/OL]`。表 A.1 中 CP 仍是计算机程序的类型代码，EB 仍是网站、网页的类型代码。

## 其他已出现的相关示例类型

标准中已有：IEEE 会议论文 `[C/OL]` 带 DOI（8.6.3）；CVPR 论文 `[C/OL]`；带 `CSTR:` 的学位论文（8.7.2）；用文章编号代替页码的期刊论文（7.7）；online-first 期刊文先按日期著录、待正式卷期后再著录卷期（8.5.3）。学位论文作为被引文献时，引文页码为有则必备；电子版学位论文著录 URL，PID/CSTR 可选。会议论文若未以图书或连续出版物形式正式出版，按 8.6.3 不必强行补图书式出版项。

## 2015 → 2025：计算机应用技术论文差异表

据 2025 前言「主要技术变化」及条款表整理，不采未核实的第三方评论文字。

| 事项 | 2015 常见做法（据 2025 前言的表述） | 2025 应执行的规则 |
| --- | --- | --- |
| arXiv / ChinaXiv / bioRxiv | 无专类，常被挤进 EB 或 J/OL | `[PP/OL]` + 平台 + 创建或修改日期 + 引用日期 + URL/PID |
| 数据集（数据中心、Zenodo、GitHub Release 等） | 已有类型代码 DS，但无 8.x 专节格式 | 8.14 格式；引用日期必备；PID 已在 URL 中则不必重复 |
| 软件 / 网页 | 已有类型代码 CP；EB 常被释为「电子公告」 | 仍无软件专章；表 A.1：CP = 计算机程序，EB = 网站、网页；同一 Zotero 条在 8.11.3 为 `[CP/OL]`、在 B.10 为 `[EB/OL]`，视为标准自身未决不一致 |
| DOI / CSTR / URN | 以 DOI 为中心 | 纳入 PID 家族；路径已含 PID 时不重复（7.9） |
| 拉丁文或拼音姓氏 | 工具常输出全大写姓 | 仅首字母大写（`Einstein A`，不是 `EINSTEIN A`）；拼音名宜用全称（7.1.1） |
| 责任者超过 3 个 | 常见做法是著录前 3 个加「等」 | 不超过 3 个应全部照录；超过 3 个时**可**著录前 3 个加「等」（7.1.2，许可而非「应」） |
| 引用日期 | 电子文献上使用较广 | 对网站、数据集、预印本仍为必备 |
| 被引学位论文 | 已有规则 | 8.7 格式；引文页码有则必备；电子版给 URL，PID/CSTR 可选 |
| 未成书的会议论文 | 类型化较弱 | 8.6.3：非图书/连续出版物时不必套图书式出版项 |

学校模板若仍规定按 2015 著录，或像东南现行格式规定那样**未写明 7714 年份**且类型代码仍用「电子公告」，先执行校规，不要悄悄改用 2025 示例；同时准备得起上表说明。见 [格式与引用](format-and-citations.md)、[学校叠加层](school-overlays.md)。
