# 复旦大学 2025 学术学位（自然科学）博士评阅书

这是**学校评阅表格**，不是教育部统一的学术型（非专业学位）评阅模板。第3轮未找到全国统一的学术型评阅书。不要把本表折算成西电工程类专业博士 2025-01-07 表的 20/20/50/10，也不要折成西电 2025-01 学术博士资料包内评阅书的选题 20 / 创造性 56 / 科研能力 24，更不要用 [学位办〔2024〕18号](moe-professional-doctorate-2024.md) 来套学术型计算机博士。用户学校若另有评阅书，改用该校栏目。综述性意见组织见 [审查量表](review-rubric.md)，勾选稿见 [review-checklist.md](../templates/review-checklist.md)。

## 申请人自评

自评页由**申请人**填写「**论文的主要创新点（仅罗列要点）**」，提供 **1. / 2. / 3.** 三个编号栏，并写「不够填写，可另附页」；另有「论文存在的不足之处及改进设想」。这是该校 2025 自然科学学术博士评阅书的栏目设计，不是国家规定的创新点条数，也不是强制至少三项，更不是评阅人必须列出三项或填「无」。

## 四项百分制指标

评阅人按下列四项打分，**每项百分制**：

1. **选题：** 选题的前沿性和开创性；研究的理论意义、现实意义；对国内外该选题及相关领域发展现状的归纳、总结情况。
2. **创新性及论文价值：** 对有价值现象的探索、新规律的发现、新命题新方法的提出等新的科学发现；对解决自然科学或工程技术中重要问题的作用；论文及成果对科技发展和社会进步的影响和贡献。
3. **基础知识及科研能力：** 论文体现的学科理论基础坚实宽广程度和专门知识系统深入程度；研究方法的科学性，引证资料的翔实性；作者独立从事科学研究的能力。
4. **论文规范性：** 引文的规范性，学风的严谨性；文字表述的准确性、流畅性与结构的逻辑性。

## 总体评价、答辩结论与异议

- 对学位论文学术水平的评价：A 优秀 / B 良好 / C 一般 / D 差。
- 是否同意参加答辩：A 同意；B 基本同意，略作修改后答辩；C 须作重大修改，重新送审通过后答辩；D 不同意。

评阅书出现以下**任一**情形，界定为「存在异议」：

1. 学术水平评价为「差」；
2. 答辩结论为「须作重大修改，重新送审通过后答辩」或「不同意」；
3. 评价表中**任何一项**评价指标**低于 60 分**。

异议论文**至少修改 3 个月**，重新送审通过后方可答辩。
