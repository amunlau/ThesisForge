# 审查量表

用于 `review`、预答辩阅读、投稿前自审和按意见返修。目的是找到会妨碍专家判断的问题，而不是生成一份很长的挑剔清单。检查单辅助判断，不代替判断。可勾选的工作稿见 [review-checklist.md](../templates/review-checklist.md)；意见格式见 [review-report.md](../templates/review-report.md)。

## 问题等级

| 等级 | 含义 | 处理 |
| --- | --- | --- |
| **阻断** | 学术不端风险；核心主张缺乏证据；实验设计或数据有致命缺陷，主张不能成立；严重的一文多投/未披露前作 | 必须修复或明确撤回相应主张后再谈发表或送审 |
| **主要** | 综述不能定位缺口；创新点与正文不一致；基线过时或不公平；方法回答的不是所提问题；摘要夸大；主线断裂（拼装论文）；关键实验缺失导致 warrant 不足 | 应修；在审查报告里给位置和改法 |
| **次要** | 个别病句、格式不统一、图注不完整、可压缩的重复 | 集中处理，不因次要项阻断交付，也不无限扩大范围 |

不要把“还可以再做一组并非支撑原主张所必需的实验”写成阻断或主要项。不要因为风格偏好（只要不违反学校/刊物规定）判错。不要把「句子不够对冲」当成创新点不明确。这一分层与「不要因非必需实验升级问题」的校准依据包括 Sewell 坏理由第 7 条（主张已被合理支撑时仍要更多评价），NeurIPS 2025 审稿指南以 “Are claims well supported (e.g., by theoretical analysis or experimental results)?” 提问的方式，以及会议侧补充：ICLR 2026 Reviewer Guide 以 “Does the paper support the claims?” 提问，并写明未达 SOTA 本身不是拒稿理由，追加实验「should be limited in scope and serve to more thoroughly validate existing results」（与 Sewell 坏理由第 7 条同向）；CVPR 2026 Reviewer Guidelines 要求质疑「has been done before / 缺乏新意」必须给出具体文献并说明相近程度，只说「this is well known」而不引用是不够的。不要把 ICLR 对近两个月同期工作或仅 arXiv 工作的比较规则、或 CVPR 数据集须在 camera-ready 前公开的时点，写成学位论文规则。不要把 NeurIPS / ICML / ICLR / CVPR 的栏目抄成学位论文法定轴，也不要发明全国分值。主题句先行、「三条通常强过六条」继续只作为建议。

## 学术型审查的四个轴

**问题类别与严重度分开。** 逐条意见以“【大类｜具体问题】”开头。六类为 AI味与文风、篇章与逻辑、格式与排版、文字与语法、事实与技术、依据待核；定义、误报控制、定位与例子见 [自然写作与文稿终检](natural-writing-and-review.md#六类问题与三级严重度)。空泛表达通常为次要；技术错误或关键缺证据按影响定级，不能因为文风像模板而认定不端。相同根因合并关联位置，不为充数重复批注。

默认按以下四块组织意见（与常见评阅书栏目对齐，但不发明全国分值表）。学位〔2014〕5 号《博士硕士学位论文抽检办法》第 5 条要求「按照学术学位和专业学位分别制定博士学位论文评议要素和硕士学位论文评议要素」；办法正文没有分值，也没有公布要素细目。第 8 轮 moe.gov.cn 源页 HTTP 500，已用北京大学研究生院转载 PDF、上海中医药大学转载 PDF、大连理工大学转载页及官方 URL 的 Internet Archive 捕获核对。教督〔2024〕1 号《博士学位论文抽检改革方案》（2024-12-04）把博士学位论文表述为「做出创新性成果的系统性体现」，并要求「分类研制抽检评价指标体系」、优化专业学位抽检评价要素；第 8 轮打开的是海南大学研究生院转载 PDF（PDF 自身创建时间为 2024-12-05），moe.gov.cn 源页未打开。已打开文本同样没有全国评阅分值或 12 项要素的新细目。这是抽检组织的改革方案，不是与《学位法》并列的新法律条件——学位法「创新性成果」仍只约束博士，不要把抽检方案写成硕士也依法必须列出创新性成果。不要把未打开的 2018 年提案答复函检索摘要中的「4 个评议指标 / 12 项评议要素」写成已重核的现行抽检细则，更不得补造分值；即使将来打开该函，也须注意教督〔2024〕1 号已要求分类研制/优化指标体系，不能假定 2018 年表述仍是未改的现行细目。

1. **选题：** 是否来自真实问题、范围是否可完成、题目是否诚实。
2. **创新点是否清楚、紧凑：** 每条是否写清承继、突破、价值与证据，彼此可区分，并与摘要、第1章、结论对读。问的是主张是否清楚、紧凑，不是是否堆了足够多的限定语。第 2 轮曾见的西电「创新点是否明确、凝练」是否栏本轮未重核，不得再当作已重核依据。创新点放在第1章还是结论，以学校为准；已打开的北大 2018/2019 写作指南、2007 年《基本要求与书写格式》，以及清华 2025-03、东南、西工大、华科、南大 2007 试行规定，均未把创新点定为第 1 章必备标题，不得恢复「北大必须第 1 章」。审查时不要仅因条数不是 3 就列为主要问题。
3. **论证与证据：** 方法、实验、仿真或测量是否与主张类型相称（系统评价、通信仿真统计、器件物理验证、机器学习划分与泄漏等，见 [实验设计](experiment-design.md)）。工作量按主张与证据是否相称来衡量，不以页数或实验组数计量。注意是否把事后假说写成事先假说，机器学习部件有无泄漏或顺序过拟合，缺失数据是否冒充观测，器件等明确物理量的测量是否报告了不确定度口径。不要把未使用 research-to-report-and-briefing 或 Unbot 写成阻断项。
4. **规范性与表述：** 结构、图表、参考文献、术语；过虚或过防；学校模板与所适用的标准。

**专业学位的评阅依据。** 依据学位层次、专业类别、申请路线及本校评阅书选取栏目。共同关注工程问题、个人贡献和可核查的应用价值。对电子信息等八类工程专业硕士，核对其选用的应用研究型专题论文或实践成果形式和相应证据。对工程类专业博士，核对博士路线所要求的实践创新和材料。工作量结合研究难度及证据评价。[工程硕士与 0854 类别要求](topic-and-contribution.md) · [工程类专业博士要求](moe-professional-doctorate-2024.md)

**学校评阅书是示例，不是全国法律，也不要互相折算。** 第 2 轮曾打开的西电评阅送审通知页（`https://gr.xidian.edu.cn/info/1073/13806.htm`）本轮 HTTP 404、Internet Archive 无 200 捕获，故其中学术博士选题 20% / 创新性 20% / 科研能力 50% / 规范性 10%，以及对「创新点是否明确、凝练」的是否判断，**不得再写成已重核的现行学术博士规则**；「明确、凝练」标为第 2 轮曾见、本轮未重核。2025-01 官方学术博士资料包内评阅书日期为 2018-10-15，权重为选题 20 / 创造性 56 / 科研能力 24，无「明确、凝练」是否栏；自评表为创造性成果 1–5 栏并可续页。工程类专业博士评阅表已由 2025-01-07 通知更新，权重为选题与综述 20 / 专业基础及工程实践能力 20 / 研究内容、实践创新性及工程应用价值 50 / 学术规范与写作水平 10，只作专业博士示例，不得折成学术博士表。复旦大学 2025 学术学位（自然科学）博士评阅书是另一套学校表格：四项百分制为选题、创新性及论文价值、基础知识及科研能力、论文规范性；申请人在三个编号栏「仅罗列要点」，不够填写可另附页；总体评价「差」、答辩结论为「须作重大修改，重新送审通过后答辩」或「不同意」，或任一指标低于 60 分，即构成异议，须至少修改 3 个月并重新送审。详见 [fudan-review-2025.md](fudan-review-2025.md)。第3轮未找到教育部统一的学术型（非专业学位）评阅模板。用户学校若有自己的评阅书，改用该校栏目；不要把复旦四轴折成西电工程类 20/20/50/10 或学术博士资料包的 20/56/24，也不要用学位办〔2024〕18号去套学术型计算机博士。

## 通审顺序

1. 诚信与归属红旗
2. 题名—问题—主张是否同一件事
3. 创新点是否可溯源、可区分、全文一致，并且清楚、紧凑
4. 相关工作是否比较而非罗列
5. 方法与实验是否支撑主张（含基线、指标、统计、范围；证据类型是否匹配主张）
6. 相邻工作章解决的问题能否接回同一主张，工程类专业学位博士的材料能否对应所选申请路线
7. 摘要与结论是否越界
8. 表述是否过虚、过防、机械重复或突兀；语言、数字、符号与单位是否有误
9. 格式与引用是否妨碍阅读

按上述顺序形成意见后，独立完成 [最终版本终检](natural-writing-and-review.md#最终版本的独立终检)。核对意见与逐字原文、图表及上下文，撤销已被解释的疑点；覆盖用户指定的整个范围，明确未读或待核位置。只审阅时仍保留原文；零项意见同样需终检。

## 全文自洽六步检查

审查学位论文或期刊稿时，按学校或刊物叠加执行，不要全国同一位置（出处与限度见 [论证与逻辑](argument-and-logic.md)）：

1. 题名、摘要、第 1 章或引言贡献句、各章主张、实验/证明/仿真条件、结论或创新点卡片，是否讲同一组对象、范围和条件；不一致时按各项主张的直接证据核实、保留反例并界定范围。审查西工大 / 华科稿时，对读摘要是否突出创造性成果或新见解。华科各章「严密的逻辑论证关系」、结论「有机联系的论点」只作为该校叠加，不是新的全国主线法律依据。
2. 摘要是否整段复制结论或引言；结论是否只是各章小结的拼接（中科大、哈工大、国科大、上交、南大 2007 试行规定并标明「仅供参考」、浙大、7713.1）。南大除绪论外各章小结须写本章工作、特别是创新性成果；西工大 / 华科结论应阐述创造性工作或归纳有机联系的论点。北大 2014 年 4 月答辩指南「摘要不是引言的翻版」若使用，须标文件名，且只约束该校流程，不要算进 2007 年格式文件，也不要做成全国禁令。
3. 方法中出现的设定、数据集、工艺或信道是否在结果中出现；结果中出现的指标是否在方法中交代（中科大）。
4. 图表、符号、假设是否被主张收窄或夸大；「首次 / 优于 / 显著 / 极大地改进」是否与证据同域。通信学报英文文摘对「极大地改进」「本工作首次实现了……」「经检索尚未发现与本文类似的工作」的禁例，只作为该刊英文文摘的可执行禁例，不要做成所有产品的法定词表。
5. 实验或仿真是否只给曲线和结论、不叙述条件与过程（哈工大；通信稳态随机性能估计沿用 Pawlikowski 规程，有限批次核对终止条件与配对，不写 BER 事件数）。
6. 作者本人工作与他人工作是否分开（国科大结论、北大 2007 年《基本要求与书写格式》结论、哈工大主体、软件学报「明确标引」）。0835 对他人代码、文档、数据等须明确标示，可作软件方向参考，不是全国新禁词。

不要把哈工大结论禁用「大概 / 或许 / 可能是」或「结论一般 2000 字以内」、南大绪论字数、华科文献篇数、西工大第三人称摘要或通信学报英文文摘禁例做成全国默认；不要把主题句先行升为硬规则。

## 学位论文快速清单

- 题名是否清楚交代研究对象和任务，泛称是否掩盖有助于区分工作的关键信息
- 摘要是否背景过多、是否夹带参考文献、中英是否区分 thesis/paper；字数是否落在学校窗口（学校未提供时，中文论文先按 7713.1—2025 的 300–1000 字核对，外文论文的中文摘要才看「宜不少于 5000 字」）
- 摘要人称是否符合该校或该刊规则
- 摘要、第1章、结论的内容与创新点是否一致
- 第1章是否过早堆引，第2章是否重复清单
- 后续章是否再写一遍相同的相关工作
- 各工作章是否回指总题，还是独立小论文并列
- 算法输入输出与代价是否清楚；定理是否有证明且归属清楚
- 比较是否包含近期接近工作
- 工作量是否按主张与证据是否相称来衡量，而不是清点页数或实验组数；是否把事后假说写成事先假说
- 机器学习部件有无泄漏或顺序过拟合；缺失数据是否冒充观测；器件测量是否报告了不确定度口径
- 公式是否定义了却不用；符号正斜体是否混乱
- 图表编号、三线表或模板表样式、正文引用
- 参考文献过旧、或明显该有的中文/英文重要工作整类缺失（视题目而定，不是“必须有中文文献”的教条，但武大计算规范曾批评“一篇中文文献都没有”的情况，审查时按题目领域判断）；学校若规定最低篇数或近五年比例，按学校叠加层核对
- 章节是否按模板另页起；标题中是否误放标点或文献
- 前置要素是否按学校模板及 [表 A.1 清单](../templates/front-matter-checklist.md) 齐备

## 期刊稿快速清单

- 是否属于该刊范围；是否把会议稿原样换题
- 摘要是否自洽、是否含正文没有的信息；字数、关键词、创新点栏目是否符合该刊卡片（见 [journals-cn.md](journals-cn.md)、[ieee-style.md](ieee-style.md) 或 [venues-acm-elsevier.md](venues-acm-elsevier.md)）
- 引言是否夸大或饵诱（开头许诺的和正文做的不是一回事）
- 评价是否达到该刊习惯（T-ED 一般应有至少部分直接物理验证、系统稿的系统评价、通信稿的假设一致与统计；未使用未核实的 BER 事件数阈值）
- 结论是否抬高或引入新概念
- 可复现信息、伦理、AI 政策、前作披露

## 审查报告写法

使用[审查报告模板](../templates/review-report.md)。按实际委托给结论。整稿送审判断需要相应覆盖，局部审阅只说明该范围内的发现。意见附类别、严重度、判断依据、最小修法及可复核的位置。文字问题附原句，图表或缺失项标出具体对象。材料不足时交代对判断的影响。

返修时逐项对照实际改动或维持理由。复核确认解决后再关闭；仍缺必要材料或问题处于委托范围外时保留开放状态，标明影响。
