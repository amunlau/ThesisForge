# 按委托启用的扩展

本技能继续以计算机、通信和电子工程研究为主。以下扩展有实际任务时才加载；没有工具时说明可做范围并继续独立工作，不把可选依赖变成普通写作的门槛。

## 导师式指导与独立复核

用户要讨论选题时给出理由式诊断：当前可试验、应缩小范围、缺决定性证据或暂不可执行，并说明下一项能区分判断的工作。用户要求教学辅导时才用逐章提问与练习；已委托自主研究时主动提出、实施和核验方案，不等用户逐阶段批准。

整稿 `deep` 预审按问题选择方法、理论、文献、工程实现、统计或图表视角。独立检查者先看原材料和本次目标，再形成发现；综合时核对原句、版本、证据和重复意见。相同模型扮演多个角色不等同多位独立专家，意见数量不是论文质量指标。短任务不固定启用多个代理。

跨供应商模型复核默认关闭。有明确需要时先确定可发送材料、供应商、预算和实际可用工具，再提供最小必要材料；API key 存在不等于允许上传未发表稿。不能访问另一个模型时仍可做当前宿主内的独立审阅，并如实说明。

## 文献工作流

本地材料优先用 BibTeX、RIS、JSON 或用户已有文件；保留原条目、来源文件、解析位置和拒绝日志。导入成功不等于题录已核实，也不证明文献支持主张。只在真实需要时连接 Zotero、Obsidian 等应用，先查实际接口和版本；不读取无关库、改全局配置或要求用户重复提供可读材料。[文献检索](literature-search.md)

本包的[本地题录工具](../scripts/import_bibliography.py)提供具体输入范围和拒绝日志，调用方式与解析边界见检索指南。先核导入结果，再按真实研究需要筛选、检索和阅读全文。

系统综述筛选、benchmark 设计及元分析的方法入口见 [评测与文献综合](benchmark-and-synthesis.md)。普通相关工作不自动启动双人筛选或 PRISMA。正式效应量合成须先验证可合并性、数据和统计方法；本包没有通用元分析执行引擎，不能将提示词或 schema 说成已经做过统计。

文献更新先交可执行的查询、已读版本、上次日期和待核更正清单。只有用户明确要求持续监测时，才使用宿主实际支持的任务/提醒功能，并确定周期、期限与通知方式；普通研究不偷偷创建持续任务。

## Word、LaTeX、Typst 与答辩

Word 和 LaTeX 的执行及验收见 [文档工作流](document-workflows.md)。Typst 暂不内建专门编译器；用户给出 Typst 工程时，使用实际可用后端、保护源文件、记录真实构建与最终版面，缺工具时说明需要的依赖，不伪称已有完整专项支持。

要制作答辩稿时，优先调用当前可用且适合交付格式的演示技能/工具。ThesisForge 提供研究主线、证据、技术解释、图表源和保真验收：按听众建立理解前提；由论文问题和结果决定讲述顺序；正文、图、公式、数字和贡献不能为叙事变强；实际 PPTX/PDF、讲稿和备注要对应。没有指定工具时按实际能力完成；不把 Beamer/Touying 设为所有答辩的强制后端，也不虚报可编辑对象或未检查页面。

学校配置优先补当前用户目标学校、学院、年份和学位类型。刊物文体可结合用户自己的样稿和实际读过的目标文章校准；语料不足就使用中性学术表达并记录限制，不要求固定篇数，也不假称学到了某刊独有风格。[学校叠加](school-overlays.md)

## 图形制作与复刻

科研图采用匹配表达任务的工具：Mermaid 适合流程/状态关系，draw.io 适合可编辑系统框图，绘图库适合真实统计图，电路/波形采用相应工程工具。外观复刻只在用户明确委托且素材使用范围允许时做，交代原来源、调整和实际可编辑部分；默认新论文按真实设计制作原创关系图。图表数量、密度和字体以 [工程图表](engineering-figures-tables.md) 为准。

[render_diagram.py](../scripts/render_diagram.py) 可调用已安装 CLI，将源文件复制到全新输出目录，保存命令、工具版本探测、日志、源/产物指纹和有限格式检查。它不自动下载 `npx` 包、不更改源图；相对图片等外部依赖需先在获准项目中打包为自包含图源。缺后端时按 [环境规则](compute-environment.md) 处理。配置项以实际安装版本的帮助为准。[Mermaid CLI](https://github.com/mermaid-js/mermaid-cli) · [draw.io 命令行导出](https://github.com/jgraph/drawio/wiki/Desktop-App)

```text
python -B <技能目录>/scripts/render_diagram.py design.mmd --backend mermaid --output-dir figures/build-01 --format svg
python -B <技能目录>/scripts/render_diagram.py system.drawio --backend drawio --output-dir figures/build-02 --format pdf --page 0
```

Windows 的 Mermaid 若仅有 `.cmd` 启动器，使用实际 Node 可执行程序及本地已安装的 CLI JS：`--program node --entry <本地MermaidCLI入口.js>`，不拼 shell 字符串。成功状态为 `exported_not_visually_verified`：SVG 仅检查 XML 结构，PDF/PNG 仅检查文件头；仍要核原图的语义、标签、目标栏宽字体、线条和最终页。draw.io 多页图显式选择页并核对覆盖，默认导出不保证全页。

## 交叉学科与人体研究

工程论文涉及理论证明、用户研究或工程案例时，按该证据类型审阅，不强制算法论文结构。医学、法学、基金预算等完整领域另作明确扩展，不仅因论文含一个相关词就启用。涉及人体、个人数据或机构审批时记录实际适用规则、已有许可和缺口；没有材料不能写成已获伦理批准或普遍豁免。本包不内置某国机构的 IRB 提交判定，具体材料按目标机构现行指南组织。
