# 评测论文与文献综合专项

在研究问题涉及评测负载、数据集、评分方法、系统综述或定量文献合成时加载相应小节。普通新方法论文继续用[实验设计](experiment-design.md)，只借用与当前问题有关的检查。此处提供研究规程和验收条件；真实实验仍通过[自主计算研究](computational-research.md)执行，不以填表或生成数据替代运行。

## 评测或数据集作为贡献

先说明既有评价遗漏了什么：未覆盖的条件或能力、实际被违反的假设、过粗的评价粒度，或无法区分的机制。新评测的规模和难度可描述，但它应让读者得到原有评价难以得到的判断。检索最接近的基准，比较对象、构造来源、输入粒度、评分和覆盖边界，避免只比较样本数量。

可用[评测方案](../templates/benchmark-plan.md)记录如下闭合关系：

`待判断的研究问题 → 覆盖轴与排除项 → 数据/负载构造 → 可信答案或判据 → 被评方法与预算 → 分层观察 → 有边界的发现`

### 覆盖与构造

按机制选独立、可解释的轴。NoC 可用流量来源、空间分布、突发性、负载强度、包长和拓扑中的相关子集；HDL 可用功能、复位/握手状态、边界输入及合法时序；AI 可用任务、来源、难度或分布变化。轴的含义与生成方法必须明确，不能把相关变化当作只改变一个因素。组合太大时根据主张与预算设计覆盖，记录未覆盖的组合，不声称穷尽。

构造管线逐阶段记录输入、操作、输出、数量变化、版本、检查及失败处理。可以采用真实采集、受控扰动、从已知性质构造实例或生成后筛查，分别说明偏差。预设答案再生成问题不自动保证问题唯一或无捷径；检验构造器和评分器，保留无效实例的原因。对人工标注保存标注规则、实际标注者角色、抽查方式、分歧及裁决，报告实际工作量和适用的一致性分析，不编造多人复核。

合成 NoC 负载须核拓扑合法性、源目的、释放时间、包长、注入/交付分母、排空与超时。验证自定义流量生成器是否实现所称分布；真实 trace 的采集时间、抽样及匿名处理另记。人为设计的最坏情形可检验边界，不能未经理由代表典型使用分布。参考答案应有独立检查依据，避免用与候选同一份实现给自己评分。

### 划分、污染与公平协议

训练、调参、基准构造和最终评价各有使用边界。先按对象、来源、时间或结构近重复关系划分，再检查交叉泄漏；仅做文件哈希去重不能排除近重复。若基准公开后被用于训练，记录评价模型的版本和已知污染证据，不因为“新合成”就承诺无污染；生成器本身也可能接触原基准。提示中泄露答案、评分器偏好某种表述、测试集饱和分别诊断。

选有解释力的基线，考虑方法族、资源规模、专长和当前近邻；经典简单方法仍可有重要对照价值。数量随主张和预算确定，基线获得合理配置与可比调参机会。模型输入格式、解码、输出解析、重试、超时和失败计分在看结果前固定。HDL/仿真按各自的事务或事件判据评分，不移植文本模型的得分规则。

保留每例输出与评分明细，用小规模已知答案核对正确、错误、空输出、异常及边界情况。LLM 评分若使用，说明它的角色、模型版本、随机性、顺序偏差及实际人工/独立标注校准；它的判断不自动等同真值。系统吞吐、时延、精度与资源成本分别统计，不能在成本不同的条件下仅凭榜单宣布机制优越。

### 从榜单走向发现

先回答总体问题，再沿主张选择分层表现、难度变化、尾部、错误类型和代价。错误分类有可操作定义和可复查样本，未知归因保留未知。成功、失败、反直觉和边界案例按说明过的原则选择；这些案例用于解释聚合观察，不能替换总体分析。

每个核心发现连接具体比较、数值/事件、条件及解释边界，再说明对方法选择或下一步研究的影响。总体领先但特定条件落后时保留两者；未能区分的方法不要强排先后。根据覆盖限制区分“该基准下观察到”和“可以推广到”；不要把任务成绩直接当作普遍理解、推理或安全能力。

发布或交付基准时保存数据来源和适用许可、构造与评分版本、使用划分、失败处理、运行条件、逐例结果和复跑入口。研究材料受限时交可披露的协议、样例或替代验证，并说明无法独立核查的部分；只有用户要求发布时才进行外部发布。生成论文中的数值和图表仍从真实记录重建，见[数据分析](data-analysis.md)。

## 明确委托系统综述时

按[文献检索协议](literature-search.md)先确定问题、可执行检索源、语言、时间、纳入/排除标准、数据提取项与停止条件。系统综述、范围综述与一般相关工作分别表述，不因采用一张流程图就更改研究身份。

1. **导入与去重。** 保存原始题录、检索来源、查询日期、文件身份和原 ID。区分同篇重复、预印本/正式版、同一研究的多份报告；去重/合并映射和导入失败条目可回查。
2. **校准筛选。** 用种子文献与一批不同情形试行纳排标准，修订歧义后记录协议版本。高影响或正式双人筛选由独立判断者先各自分类，再处理分歧；没有第二位真人时不得声称“双人专家筛选”，模型辅助和人工工作分别记录。
3. **题摘与全文两阶段。** 每条记录保留阶段、决定、排除理由和依据位置。全文不可得与不符合标准分别计数；边界/近失误记录复查是否因措辞或解析遗漏错排。筛选角色不猜未读全文内容。
4. **提取与质量评价。** 比较任务、设计、样本/条件、方法、结果和限制。独立报告可能共享数据，不能算作独立重复证据。质量判断绑定实际设计，刊物级别、引用数或年份不能独自决定可信度。
5. **综合与报告。** 围绕问题、机制和冲突条件组织。按实际执行的流程输出数量和排除原因，可采用适用的 PRISMA/SEGRESS 报告结构；协议变更注明发生时点和原因。筛选表、来源表可导出 CSV/TSV、RIS 或目标表格格式，说明字段与遗漏。

独立复核按风险和资源安排，不机械固定代理数、抽样百分比或每主题篇数。预算耗尽而核心缺口未解决时如实交范围与待查事项，不能把工具返回的 PASS 当作系统性或科学正确性的认证。

## 元分析仅在可合并性成立时展开

本技能提供方法入口，不内置通用元分析执行器。收到实际委托后，先核各研究是否回答足够相近的问题，效应量、对照、时间点、协议与独立性是否可比较。不同流量、预算或任务上的相对性能不能直接平均成一个“总体提升”。同一论文的多组结果、同一数据集的多方法结果可能相关，应选择能处理相应依赖的设计。

需要正式合成时，在研究项目中选择有适用依据的统计工具并实际验证：效应量与方差提取、必要的转换、缺失量处理、合成模型及假设、异质性、敏感性和偏倚诊断。复算一项提取值和一个已知例子，再运行全部数据；保存输入、方法、版本、输出与图。森林图呈现已经算出的结果，不能靠制图模板补齐未知方差。资料不足或不可合并时采用分层叙述/表格综合，说明为什么没有给合并效应。工具、检验和阈值随研究问题核实，不预设一个普适显著性或异质性门槛。

## 后续更新与适用范围

保留查询、最后核验版本和会改变判断的新证据类型，供以后重查。定期监测文献、更正或撤稿只在用户明确委托持续任务时设置频率、期限和通知渠道。人体参与或个人数据相关基准还需本地适用的授权、伦理和隐私条件；本页不代替机构审批，也不将其扩为所有计算实验的固定流程。
