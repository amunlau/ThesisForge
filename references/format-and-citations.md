# 格式与引用

工程论文的原创框图、流程图、数据图及结果表，可在[科研图表指南](engineering-figures-tables.md)中找到按最终版面检查字号、有效分辨率、配色和表头的方法。

学校或目标期刊指定的模板、采用的标准版本及投稿阶段，决定本稿的格式检查口径。GB/T 7713、GB/T 7714 等属于推荐性国家标准，学校或刊物明确采用时按其适用条款核查，未指定时可作默认参考。标出条款中的“应”“宜”及资料性示例，避免将建议列为违规。法律和适用的强制性规定另行核对。[《标准化法》第二条](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2023/art_d7040b9f1d0f4980a0e55089a57bf37d.html) · [GB/T 7713.1 的官方类型与状态](https://std.samr.gov.cn/gb/search/gbDetailedCNF?id=3B46A026CC84469CE06397BE0A0AEEB8)

条款原文、表 A.1 和 7714 示例不要在未打开下列文件时凭记忆展开：学位论文编写与排版底线见 [gbt-7713.1-2025.md](gbt-7713.1-2025.md)，期刊轨道编写底线见 [gbt-7713.2-2022.md](gbt-7713.2-2022.md)，参考文献见 [gbt-7714-2025.md](gbt-7714-2025.md)，文摘编写见 [gbt-6447-2025.md](gbt-6447-2025.md)，关键词见 [cyt-173-2019.md](cyt-173-2019.md)，学校窗口、排版叠加与「谁已切换到 2025 国标」见 [school-overlays.md](school-overlays.md)。

按 GB/T 7713.1—2025 检查的印刷学位论文，正文从另页右页开始，各章另起页。图号与图题置下，表号与表题置上，三线表属推荐形式。6.10 对天头和订口规定至少 25 mm，对地角和切口规定至少 20 mm。题名长度、注释、章题占行、页码和附录见[学位论文编排条款](gbt-7713.1-2025.md)。具体字体、字号、行距及各章是否都从奇数页开始，查学校模板。

## 摘要字数：国标默认 + 学校叠加

GB/T 7713.1—2025 **5.2.9**（已与大学馆藏及华侨大学可抽取文本核对）：

- 用中文撰写的学位论文：中文摘要一般 **300 字～1000 字**，特殊需要可略多。
- 关键词 **3 个～8 个**，编写符合 CY/T 173（见 [cyt-173-2019.md](cyt-173-2019.md) 与 [keywords-checklist.md](../templates/keywords-checklist.md)）；英文摘要为宜、另页、与中文对应。
- **为能完整描述学位论文的主要内容，中文摘要宜不少于 5000 字**——此下限只适用于**外文学位论文的中文摘要**，不得套到普通中文论文。

**先区分三类摘要窗口，不要混用：**（1）论文前的短摘要；（2）学校另册要求的详细摘要（如西电详细摘要分册）；（3）留学生或外文撰写论文的详细中文摘要（国标「宜不少于 5000 字」、西工大/国科大 40 号及微电子文件的「宜不少于 / 建议一般不少于 5000 字」、清华国际研究生则是 800–1000 汉字且限一页，哈工大留学生详细中文摘要不少于 3000 字）。复旦 2026.06 对非中文撰写论文的中文摘要是 **1000–3000 字**，必须与 5000 字窗口分开，不能混用。浙江大学《编写规则》（2014 年生成的校级规则；现场官方 URL 本轮仍 HTTP 500，文本取自研究生院官方 URL 的 2024-10-06 / 2025-08-08 存档）用原文「硕士论文摘要的字数一般为300--500个左右，博士论文摘要的字数为500-1000个」（保留官方「个」）。这是校级短摘要，不要和 5000 字窗口、复旦 1000–3000、清华一页 800–1000 混用；该文件未给出页边距，不得补造。

学校手册是叠在 5.2.9 之上的窗口，不是对国标的废止。例如清华 2025-03 为 800–1000 字（一页为宜；国际研究生的中文摘要为同一窗口），北大 2018/2019 与仍在流转的 2014-05 指南均为博士 800–1000 / 硕士约 600、东南约 500 汉字、中科大 2026-10-29 模板博士 800–1000 / 硕士 600 汉字、哈工大 2025-03 理工硕士 500–1000 / 博士 1000–2000、北航 2025-09 博士约 800–1200 / 硕士约 500、西电 2025-01 模板短摘要硕士约 1000 / 博士约 1500、复旦 2026.06 中文撰写论文 300–1000 字、华科 2009/2022 硕士 500–600 / 博士 800–1000、南大 2007 试行规定「一般在 1500 字」（显著宽于多数学校，且须标明文本年代，不得当成 2025 国标实施后的修订本），均须执行该校该文件窗口。浙江大学《编写规则》的硕摘/博摘窗口见上段原文，须标明 2014 年生成的文本年代。上交 2025-11 指南未给中文摘要字数，不要补造。西工大 2025 指南对短摘要本身没有给出字数窗口，不要补造；其对国际研究生详细中文摘要「宜不少于 5000 汉字」。西电详细摘要分册（硕士约 1000 / 博士约 3000）是另一文类，不得与论文前的短摘要页混用，也不得再用 2014 手册的「简短摘要约 300 字」作为 2026 默认。国科大 40 号把中文摘要字数交给学科群分会，只对外文/留学其他语种撰写的中文摘要「建议一般不少于 5000 字」；计算机/通信/0854/1401 仍默认 40 号。2022 年分会文件夹已打开：微电子仍无摘要字数；工程科学、生命、资环、天文的窗口只适用于各自分会学科，见学校叠加层。**禁止**把流传的「硕士 500–1000 / 博士 1000–1500」写成这些方向的规则。北邮规范全文仍未取得，数字保持未核实。学校若仍引用 2006/1987 或 2015/2005，或像东南现行规定那样未写明 7714 年份，按校规执行，提醒所引版本或用语可能滞后，**不要悄悄改成 2025 著录示例**（西电 2025-01 模板仍写 GB/T7714-2005，尤须先警告再按模板执行）。哪所学校已指向 2025 国标栈，见学校叠加层中的对照表。

2006 年版曾有摘要「一般不宜超过 200–300 字」等表述，不能再写成现行国标。未提供学校模板时，先推进内容与逻辑。中文撰写的学位论文可按 5.2.9 的一般范围 300–1000 字核查普通中文摘要；字体、字号、行距和封面措辞标为待套模板；边距若学校未给，只按 6.10 下限（天头/订口 ≥25 mm，地角/切口 ≥20 mm）核对，不要发明排版数字。GB/T 6447—2025 的「约 400 / 300 / 150 字」是文摘一般篇幅带，不要用来覆盖 7713.1 或学校的学位论文窗口。期刊轨道的同类数字以 7713.2—2022 4.2.3 为准（报道性/报道指示性/指示性），且先执行刊规。

## 学位论文格式检查（在已有模板时）

**先读该校编号连接符与奇偶页规则，不要统一改成一种。** 国标只说图、表、公式「可分章编号」，未规定用「-」还是「.」。已见表：国科大/哈工大/西工大为 **图1-1 / 图1-3**（连字符）；西电/中科大/北大 2014-05 / 南大 2007 为 **图1.3 / 图 2.1 / 图1.2**（点号）；西电公式却用 **(3-32)**。奇数页规则也因校而异：西电每章起始必须在奇数页；西工大「正文各部分首页为另页奇数页」，比国标「正文另页右页、章另起页」更严；国科大（含已打开的微电子文件）各大部奇数页起，但正文内部新章不必；中科大只强制第 1 章奇数页起；北航章另起页但不要求奇数页；复旦、南大要求章另起页（南大「每一章必须另页开始」），复旦未写必须奇数页。北邮 2025-01-15「每部分及每章奇数页起」仅已定位、尚未成为可执行规则。

- 封面、题名页、声明、授权页的学校固定措辞不得改写走样。国标表 A.1 中题名页、原创性声明、使用授权、摘要页、目次页为必备，封面为可选（国内学校几乎都要求封面）。学校另增的前置页（如中科大人工智能使用/未使用声明）按该校清单检查
- 中英文题名、摘要、关键词齐全；题名一般不宜超过 25 字且中英对照（5.2.3；学校若另给字数，如东南不超过 20 字、复旦中文题目 30 个汉字以内、西工大一般不超过 25 个汉字、华科一般不宜超过 30 个字、哈工大主题目与副题目合计不超过 35 字，执行学校窗口）。**先判断文类再选摘要窗口**：短摘要、详细摘要分册、留学生/外文撰写的详细中文摘要不是同一窗口。摘要独立；学位论文通常不贴图、不堆非常用符号（除非必要），不加评论、不重复题名、不复制正文（6447 7.1–7.3）。**期刊摘要是否允许公式或图表，以该刊指南或 7713.2—2022 为准**（7713.2 允许出现公式、图表，但不得出现其编号；JoS 英文指南更严）。字数与关键词个数对照学校或刊物窗口，无窗口时学位论文按 5.2.9、期刊按该刊或 7713.2
- 目录、图表目录、符号表与正文标题、图题、表题一致。中英图题表题是否强制，按学校卡片执行（国科大建议双语；哈工大博士强制、硕士只用中文；中科大「若有英文图题，另起一行」），不要做成全国强制双语图题
- 正文从另页右页开始；章从新页开始（5.3.1）。是否必须奇数页起，先读该校规则
- 标题末尾无句号；标题中不放引用。章、节编号顶格，编号与标题之间空 1 个字；章的标题占 2 行；正文首行缩进 2 字，回行顶格（6.5）。具体字号行距以模板为准
- 标题层级与编号体系单一，不中英混用两套章号
- 图、表可自明，随文出现；**图题在图下、表题在表上**；按模板的连接符分章编号（图1-1 或 图1.1），正文按编号引用。宜用三线表；续表在表上方标「（续）」或该校等价用语（如中科大「续表2.1」），并重复表头
- 公式另行起并缩格；编号右端对齐（括号、不加虚线是常见校规）；转行宜在关系或运算符号后断开。公式分章编号的连接符同样先读模板
- **算法无国标专条**，学位论文按该校图/表的题注位置与分章编号处理，或服从模板中的算法样式；不要发明「算法一律三线表」或「一律按图编号」。IEEE 稿：算法放进 figure，用 algorithmic / algorithmicx，不要用 algorithm2e 的浮动体，见 [ieee-style.md](ieee-style.md)。ACM 稿：以 acmart 文档 2.8 节为准，且不得改边距，见 [venues-acm-elsevier.md](venues-acm-elsevier.md)
- 注释宜用当页脚注（5.3.6）；学校若禁止文中夹注（如上交「切忌在文中注释」），执行学校规则
- 页码：前置罗马数字、正文和后置部分阿拉伯数字连续编码（封面除外，6.6）；页眉奇偶与装订按模板
- 边距：有学校数字则执行学校数字；未给时只核对 6.10 下限（天头/订口 ≥25 mm，地角/切口 ≥20 mm），不发明推荐边距
- 量和单位：学位论文按 7713.1 4.5 指向的 GB 3100 家族。GB 3100 现行年号仍为 1993；修订稿 2026-08-17 征求意见，编制说明建议 2028-01-01 实施。学校仍写 1993 年号则按叠加层执行，不得擅改。不要与 IEEE 手册混用
- 参考文献体例与文中引用一一对应：文中有的条目都在表中，表中有的都应被引用。未引用但有用的文献，7713.1—2025 允许放入附录「参考书目」；学校若另有「阅读型参考文献」规定，按规定分开
- 附录、致谢、成果清单、索引按学校清单齐备。致谢在国标中可在摘要前单独成页，或放入序言、前言、后记（5.2.8）；许多学校放文后。附录编号与标题各占 1 行、居中；通常另起页（6.8）
- 发现同一来源两处数字或条款冲突时，披露冲突，不代为选择（如通信学报须知「约 10 页」与格式要求「约 12 页」；西工大参考文献先写遵照 GB/T 7714、后又写按 7713.1—2025 书写参考文献）
- 标点检查按文类分段：GB/T 15834—2011 管的是汉语部分（含中外混合排版中的汉语）；中科大模板 2.10 的半角规定只约束参考文献节，正文仍按 3.3 / 15834。不要做全文半角或全文全角的一刀切
- 保密标志仅在确实需要时按学校和 GB 相关规定处理

**官方 Word 与 LaTeX 并存时，约束层仍是学校/刊物规定，不是宏包默认值。** 能提供官方模板时优先用官方模板（上交、国科大、中科大、西电等均正式双轨）。LaTeX 社区实现须对照现行指南核对页眉、奇偶页和声明页，不能把宏包选项（如 SJTUThesis 的 `zihao`、盲审开关）写成校规，除非用户用的就是该校官方压缩包并已核对与指南的差异。

填写用清单见 [front-matter-checklist.md](../templates/front-matter-checklist.md)。

## 参考文献：7714 与刊物体例

- 中文学位论文：优先用学校提供的 Word/EndNote/BibTeX 样式。顺序编码制或著者-出版年制都可能出现，以模板为准。
- 2025 版仍保留这两套体系。对计算机类最重要的变化：预印本用 `[PP/OL]`，数据集用 `[DS/OL]`（引用日期必备）；**没有计算机程序专章**，8.11 / B.10 都是「网站、网页」；同一 Zotero 条在 8.11.3 为 `[CP/OL]`、在 B.10 为 `[EB/OL]`，这是标准自身尚未解决的不一致，不要把其中一条写成唯一官方规则，也不要悄悄改正。综合意见（非官方裁定）：引用程序本身用 `[CP/OL]`，引用介绍它的网页用 `[EB/OL]`。永久标识符（DOI/URN/CSTR）已在 URL 中则不重复（7.9）；拉丁文姓氏仅首字母大写，拼音名宜用全称（7.1.1）；责任者超过 3 个时**可**著录前 3 个加「等」（7.1.2，不是「应」）。差异表与示例见 [gbt-7714-2025.md](gbt-7714-2025.md)、[citation-examples-7714-2025.md](../templates/citation-examples-7714-2025.md)。第三方评论文章的额外说法未经条款表核实的，不要写成硬规则。西电 2025-01 模板把「超过时列前 3 位加等」说成做法，并仍引 GB/T7714-2005，按该校模板执行并警告滞后。
- IEEE 期刊：以 [ieee-style.md](ieee-style.md) 与 IEEE Reference Guide 为准，常见要求包括尽量列出全部作者（有的刊明确不要 et al.）、完整题名、起止页和 DOI。图题写作 “Fig.”、表号用罗马数字 TABLE，与国标「图/表 + 阿拉伯数字」不是同一套记号，切换体例时不要混用。
- ACM、Elsevier、中文学报：各用各的体例。中文学报卡片见 [journals-cn.md](journals-cn.md)（含已核的 Journal of Semiconductors 英文指南；该刊参考文献**不是** GB/T 7714 体例）；TON 与已填写的 Computer Networks / Microelectronics Journal 刊卡见 [venues-acm-elsevier.md](venues-acm-elsevier.md)；其他 Elsevier 刊物按刊填卡，见 [elsevier-venue-card.md](elsevier-venue-card.md)，不要把那两刊的 Highlights 上限推广到未核对的标题。不要用 GB/T 7714 去“纠正”一本 IEEE 论文，也不要用 IEEE 去改一份规定 7714 的学位论文。
- 永远不编造 DOI、页码、作者或年份。核对时以出版记录或权威索引为准；有撤稿或更正的要看最新状态。

## 期刊格式

打开该刊作者指南后核对：篇幅、栏式、摘要词数、关键词个数、图表位置（有的要求随文）、补充材料是否必须随投稿提交、基金与致谢位置、照片与作者简介。语言质量不足导致无法送审的，先修到可评审，再纠结边距。中文期刊稿可参照 [gbt-7713.2-2022.md](gbt-7713.2-2022.md)，先执行刊规。中文学报现行篇幅与摘要窗口见 [journals-cn.md](journals-cn.md)（通信学报、电子学报已按第 5、6 轮官方页校正；计算机学报已按第 6 轮中文征稿简则改写，并披露英文页与修改要求中的冲突）。IEEE 摘要词数不是全局上限；第 4、5、6 轮 TCAS-I 官方作者指南页仍无「7–11、最多 14 页」表述，不得编码。IEEEtran 1.8b 的末页栏命令与算法体例已写入 [ieee-style.md](ieee-style.md)。ACM TOCS 现场作者指南本轮仍为 HTTP 403；Research Highlights 的鼓励上限约 5000 词已按 2025-05-31 官方 URL 存档写入 [venues-acm-elsevier.md](venues-acm-elsevier.md)，须保留「encourage / although the limit will not be strictly enforced」，不得再只当作检索摘录。该存档未给出常规稿页数或摘要窗口，当前要求仍待核。见 [ieee-style.md](ieee-style.md)、[venues-acm-elsevier.md](venues-acm-elsevier.md)。
