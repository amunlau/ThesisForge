# 独立研究

文献检索协议停在缺口矩阵之后，还要把贡献写成可检验的研究。本文件承接 [文献检索协议](literature-search.md)，并指向 [诚信与证据](integrity-and-evidence.md) 中的反向检索、[研究问题矩阵](../templates/rq-matrix.md)、[实验设计](experiment-design.md) 与 [数据分析](data-analysis.md)。不要另交一份开题官方表格；覆盖矩阵按问题是否得到解释来衡量，不是开题必交附件，也不要用填满格子代替证据。

0812 / 0810 出处：国务院学位委员会第六届学科评议组编，《一级学科博士、硕士学位基本要求》上册，高等教育出版社 2014 年 1 月，ISBN 978-7-04-039233-3。依据为高校转载扫描件（0812：华北水利水电大学研究生院单行本，对应上册约第 353–360 页；0810：安徽工程大学研究生院 / 河北大学研究生院上册转载，两份 MD5 相同），文本年代 2013/2014。这是该一级学科当时的基本要求，不是学位法实施细则，不是 2025 年以后的新国标，也不是全国评阅分值。引用「假造」保持原文，不改写成「伪造」。创造性成果类型与硕士质量条款的学科收录见 [选题与创新点](topic-and-contribution.md)。

## 文献协议之后的步骤

依据 0812 博士「学术鉴别能力」（上册第 355 页；硕士部分第 358 页有平行表述）：在获取文献之后，应能归纳并「以批判的眼光评价文献」，判断哪些问题已经研究过、哪些还需要进一步研究、对哪些结果或解释还存在争论，最终提出需要解决的科学问题；并「提出可通过合适的对照实验进行验证的科学假说」。同一段把这些能力写成博士生从被动到主动转变的主要标志。这是训练与评价标准，不是实验组数配额。

可执行步骤：

1. **批判性评价已纳入文献。** 在缺口矩阵之上，写清：已研究什么、还待研究什么、何处的结果或解释仍有争论。不要只堆摘要。
2. **按主张类型写验证目标。** 实证研究提出可由对照检验的假说。理论工作明确命题、假设与证明义务，注明反例会推翻哪项表述。把它们接到研究问题矩阵的证据目标与失败条件。
3. **证据与主张对应。** 正确性命题可由证明支持。算法性能比较要选公平基线，器件性能则按具体主张和目标刊要求规划物理验证。理论命题本身不要求另做对照实验。
4. **区分探索与验证，并在方案和正文中标明。** 见下一节。
5. **对决定结论的关键文献做前后向追踪，并安排一次反向检索。** 反向检索的做法见 [诚信与证据](integrity-and-evidence.md)；不要在本文件里另造一套。没找到反证，只说明本次检索结果，不写成「因此必然成立」。

不要把这段 2013/2014 年博士能力要求，写成硕士依法必须列出创新性成果，也不要写成必须另交开题官方表格。

## 用主张与证据是否相称衡量工作量

0812 硕士质量要求第 359 页第（2）条：「学位论文具有新的见解，基本观点正确，论据充分，数据可靠，研究开发或实验工作充足。」「充足」与「论据充分、数据可靠」并列，原文没有出现页数、章数或实验组数。

0810 硕士质量要求第 341 页写「论文工作量饱满」，原文没有定量定义。可以如实披露这句，并把它理解为与论据、数据、实验或计算佐证相称的系统工作；**不得发明「饱满 = 若干组实验 / 若干页」。**

一项工作是否「充足」或「饱满」，看所写主张是否被可靠数据与相称的研究、实验或分析支撑，以及失败条件是否经过检验；不以页数、图表数或实验组数作为全国或默认计量。审查时只有主张失去证据支持，才把「还缺实验」列为主要问题——这与 [实验设计](experiment-design.md) 既有审查边界一致。专业学位文本里的「工作量饱满」同样没有定量定义，不得发明页数或实验组数，也不得与 0812 / 0810 互代；见 [选题与创新点](topic-and-contribution.md) 的 0854 专节。

## 探索性与验证性工作要分开

Easterbrook、Singer、Storey、Damian，《Selecting Empirical Methods for Software Engineering Research》，2007（作者托管 PDF）把澄清问题当作选择方法的第一步，并区分早期的探索性问题与后来的知识性问题。该文同时警告：方法选择依赖本地条件，没有万能配方。不要把某一种经验方法写成计算机应用技术学位论文的必选设计。

Kerr，《HARKing: Hypothesizing After the Results are Known》，《Personality and Social Psychology Review》1998，2(3):196–217（UBC 课程转载扫描件）把 HARKing 定义为：把事后假说（即基于或受结果影响而形成的假说）在研究报告中写成仿佛本来就是事先假说。Kerr 并不反对从数据中产生事后见解，反对的是把事后假说写成事先假说。该定义可迁移；文中的问卷数据不能写成计算机学科的发生率。

Nosek、Ebersole、DeHaven、Mellor，《The preregistration revolution》，《PNAS》2018（本处打开的是墨尔本大学转载的 PNAS 版面 PDF；官方 pnas.org 直链本轮 HTTP 403）把同一区分说成 prediction（用新观察检验事先说明的问题）与 postdiction（用已观察到的数据生成解释）。预注册被定义为在观察研究结局之前定义研究问题和分析计划，用来区分哪些分析来自预测、哪些来自事后解释。他们同时写：在数据事先存在等达不到理想应用的情形下，仍有可操作的策略。预注册是可选工具，不是学位条件，也不能替代对照设计、诚实报告或理论工作。不要把「必须在 OSF 上预注册」写成学位条件。Szollosi、Kellen、Navarro、Shiffrin、van Rooij、Van Zandt、Donkin，*Is Preregistration Worthwhile?*，*Trends in Cognitive Sciences* 24(2):94–95，2020（在线 2019-12-28；DOI 10.1016/j.tics.2019.11.009）。打开的是 Radboud 机构库按荷兰版权法第 25fa 条保存的 Publisher’s version 之 Wayback 副本，不是从 Cell 官网直接取得。可并列披露 PsyArXiv 预印本 DOI 10.31234/osf.io/x36pz；与预印本对读未见足以改变已编码限度的实质性删改。该文反对把预注册当成改进科学推理或补弱理论的装置，并反对把它当作要求、奖励或推广（如徽章、资助）；预注册不能补偿弱理论，也不能诊断好科学。它仍应是可选项，不是学位条件。该文没有要求取消「事先写清主指标、事后探索必须标明」。不要写成「Szollosi 反对区分探索与验证」，也不要禁止可选的预注册。

因此：主指标、停止规则、纳入 / 剔除和对照，应在看结果之前写下（可写在 [实验方案模板](../templates/experiment-plan.md) 里）。探索性结果可以报告，但必须标明为探索或敏感性分析，不得事后改称主实验一直如此设计。分析侧的完整报告要求见 [数据分析](data-analysis.md)。

与主张类型相称的评价原则，以及 Engineering Research / Data Science / Quantitative Simulation 分册的适用范围，见 [实验设计](experiment-design.md)。
