# 数据分析

用于整理、统计、作图和解释已经存在或诚实跑出的结果。不补造缺失单元格，不用平滑曲线掩盖原始点。分析前登记与完整报告见下一节；主张强度仍回到直书 / 限定范围 / 不主张三档。

## 自行执行分析

收到“自己分析并给出结果”时，用实际数据编写并运行分析脚本。脚本重新读原始文件，生成可定位的中间明细、汇总表及解释主张所需的图。记录输入标识、字段定义、转换和输出命令。读一遍脚本生成的表，手算一个关键对照，再把数值写进正文。

### 从原始记录得到可比较结果

1. 先读数据字典或生产代码。核主键、类型、时间戳与单位、标签、缺失/非有限值，核对输入行数与过滤后的分母。图中同名“延迟”可能分别包含或排除了排队等待。需要串表时检查键唯一性及未匹配行，避免一对多连接虚增观测。
2. 按方案重建应有的“条件 × 方法 × 独立实验单位”清单，与实际运行状态对账。相同工作负载按 trace/样本 ID 和配置配对，核对输入摘要。分别标出重复、缺对、超时和失败，解释能进入每项估计的记录。超时可报告失败率或按事先规则分析删失，其值不能随意填成零。
3. 依据科学问题确定统计单位。比较同一批独立轨迹上的两种策略时，先在每条轨迹算指标，再求同一轨迹上的配对差，写清“候选减基线”及优劣方向。区间或重采样保留配对、分组及相关层次。一个训练种子下的上万包、一次训练的许多 batch 均不能代替独立训练重复。条件数少或仅有固定基准时可报告逐项差异及描述性汇总，说明推断对象。[NIST 配对观测](https://www.itl.nist.gov/div898/handbook/prc/section3/prc311.htm)
4. 报告绝对差、单位、适用条件，并按需要给相对值。检查基线分母能否使用。注明“每个工作负载等权”或“按请求/样本加权”以及为何这样选择。区分总体分位数与各运行分位数的平均。检查改变权重、排除某个困难条件或变更合理统计口径后，结论是否反转。

有预定配对的 CSV 可以直接用[配对比较工具](../scripts/compare_pairs.py)重算。先从**实验方案**导出每项条件与重复一行的 `units.csv`。从运行记录选取各有效尝试的指标文件，多个文件可一起传给 `--data`。例如 NoC 每条轨迹都记录总时延与送达数时，执行下列命令。它按每条轨迹先算周期/包，再按负载输出候选和基线均值、每对差值、差值均值及样本标准差。

在存有这两份 CSV 的研究目录运行。解释器和技能目录见[平台说明](platforms.md)。

```text
python "<技能目录>/scripts/compare_pairs.py" --plan units.csv --data measured.csv --group pattern --unit seed --method method --candidate evolution --baseline random --value latency_sum --denominator delivered --match trace_sha256
```

以标准输出的 JSON 为复核入口。若方案已冻结轨迹摘要或数据划分，可在 `units.csv` 同时保留这些列并列入 `--match`。有预定值的列会与两种方法逐一核对，其余匹配列只核两法一致。整对消失、重复、摘要错配或分母无效时，命令返回非零。大整数计数和十进制输入在每对作差前保留原精度，分数可能在 JSON 输出时舍入，复查时使用逐对差值和原始数据。送达数若因丢包而异，时延只覆盖已送达包，须另报交付率与失败。

仅 `--candidate` 和 `--baseline` 指定的方法进入本次比较。工具对每个预定实验单位等权。未配对数据、删失、生存时间、嵌套种子与重复使用同一数据集的相关性需要相应的分析设计。报告区间时注明方法。单对的样本标准差以 `null` 表示；有多对且差值完全相同时标准差为零。非零结果小于工具可输出的数值范围时，应换算单位后重算并标明单位。

使用[实验矩阵](experiment-matrix.md)执行时，在原位置将 `--data measured.csv` 换为 `--matrix runs/search/index.json --artifact metrics.csv`。工具按索引的单元 ID 定位尝试，核对运行状态和指标文件摘要。显式失败的输入复核会阻止汇总；旧记录缺少该字段时按现存证据读取。这样补跑前后的两份文件只会计入有效的一份。部分失败时先核查缺失和失败规则，再决定补跑或单独分析失败率。

### AI 训练与推理

- 按研究问题选 CPU 或加速器。先用一小批真实格式输入跑通读取、前向、损失、反向/参数更新、保存和重载。核 shape、标签、有限梯度/损失及一次有效更新。若只委托推理，使用指定检查点和预处理，先验证输出维度及对照样例。
- 在训练前按对象、来源或时间冻结划分，核对跨集重叠。预处理只在训练数据上拟合。冻结用于选参和早停的验证指标，为简单基线和候选设置可比较预算。保存训练日志、最佳检查点及选择理由；恢复训练时还需对应的优化器、步数及随机状态。测试集用于最后评价，保留逐样本预测、真值和划分标识以便重算指标。[scikit-learn 数据泄漏与预处理](https://scikit-learn.org/stable/common_pitfalls.html)
- 重载独立实例，核对重载前后预测及容差。PyTorch 推理需正确设定 `model.eval()`，按场景进入无梯度或 `inference_mode`。准确性、单样本延迟、吞吐和资源耗用分别测量。计时需定义是否含预处理、加载、传输与后处理，统一 batch、精度、线程、设备和输入形状；对稳态耗时预热并同步异步设备，多次测量。研究冷启动时单独报告冷启动。CPU 结果只支撑实际 CPU 条件下的比较。[PyTorch 模型重载](https://docs.pytorch.org/tutorials/beginner/basics/saveloadrun_tutorial.html) · [PyTorch Benchmark](https://docs.pytorch.org/tutorials/recipes/recipes/benchmark.html)
- 若主张覆盖训练流程，在预定重复中重新拟合并选取检查点。同一比较内的候选与基线共享划分和调参预算。分别记录数据抽样、初始化、增强与搜索的随机流，说明这次实际改变了哪些因素。检查点在干净进程中读取，带入训练时的特征顺序、归一化、词表或阈值。若将模型导出到另一推理引擎，先按相同输入、精度和容差对齐输出，再测延迟，注明各算子实际执行的后端及回退情况。[MLSys 方差研究](https://proceedings.mlsys.org/paper_files/paper/2021/hash/0184b0cd3cfb185989f858a1d9f5c1eb-Abstract.html) · [NumPy 随机流](https://numpy.org/doc/stable/reference/random/parallel.html) · [ONNX Runtime 推理提供程序](https://onnxruntime.ai/docs/api/python/api_summary.html)

## 分析前核对

- 数据从哪来：测量、仿真、用户提供、公开数据集。每列单位、过滤条件和剔除规则写清楚。
- 主张是什么，哪些结果是预先登记的主指标，哪些是事后探索。探索性分析可以报告，但不要事后改称“主实验一直如此设计”。登记方式见下一节。
- 分割是否干净：训练/验证/测试，校准/评价，仿真调参/最终报告。
- 复现所需的种子、脚本、工具版本是否还在。计算记录见文末。

## 分析前登记与完整报告

Kerr，《HARKing: Hypothesizing After the Results are Known》，《Personality and Social Psychology Review》1998，2(3):196–217（UBC 课程转载扫描件）把 HARKing 定义为：把事后假说（即基于或受结果影响而形成的假说）在研究报告中写成仿佛本来就是事先假说。Kerr 并不反对从数据中产生事后见解，反对的是把事后假说写成事先假说。定义可迁移；文中问卷数据不能写成计算机学科的发生率。Nosek 等，《The preregistration revolution》，《PNAS》2018（墨尔本大学转载的 PNAS 版面 PDF；官方 pnas.org 本轮 HTTP 403）把同一区分说成 prediction 与 postdiction。探索与验证在研究路径上的分离见 [独立研究](independent-research.md)。

据此：

- 主指标、停止规则、纳入 / 剔除规则和对照，应在看结果之前写下（可写在 [实验方案模板](../templates/experiment-plan.md) 里）。
- 事后改动必须标为探索或敏感性分析，并同时给出按原规则的结果。
- 预注册是可选工具，用来区分哪些分析来自预测、哪些来自事后解释；不是学位条件，也不能替代对照设计、诚实报告或理论工作。不要把「必须在 OSF 上预注册」写成学位条件。Szollosi 等，*Is Preregistration Worthwhile?*，*Trends in Cognitive Sciences* 24(2):94–95，2020（在线 2019-12-28；DOI 10.1016/j.tics.2019.11.009；打开的是 Radboud 机构库按荷兰版权法第 25fa 条保存的 Publisher’s version 之 Wayback 副本，不是从 Cell 官网直接取得。可并列披露 PsyArXiv 预印本 DOI 10.31234/osf.io/x36pz；与预印本对读未见足以改变已编码限度的实质性删改。完整出处见 [独立研究](independent-research.md)）反对的是把预注册当成改进科学推理或补弱理论的装置，并反对把它当作要求、奖励或推广（如徽章、资助）；预注册不能补偿弱理论，也不能诊断好科学，也没有要求取消「事先写清主指标、事后探索必须标明」。不要禁止可选的预注册，不要写成「反对区分探索与验证」。

Wasserstein 与 Lazar，《The ASA’s Statement on p-Values: Context, Process, and Purpose》，《The American Statistician》70(2):129–133，2016（协会原则声明，约第 131–132 页；声明写明并不试图了结基础性争论）第 4 条：正当推断需要完整报告和透明。p 值及相关分析不应被选择性报告；只报告越过阈值的那些分析，会使所报告的 p 值实质上无法解释。研究者应披露研究过程中探索了多少假说、所有数据收集决定、所有统计分析以及所有计算过的 p 值。0812 计算机科学与技术一级学科基本要求（2013/2014，上册第 355 页；硕士部分第 358 页有平行表述；高校转载扫描件，出处见 [选题与创新点](topic-and-contribution.md)）写：「不篡改、假造、选择性使用实验和观测数据。」引用保持「假造」原文。这直接支持不得只展示得意负载、不得只报告显著的那些分析。

Simmons、Nelson 与 Simonsohn，《False-Positive Psychology》，《Psychological Science》2011（大学课程转载 PDF）把未披露的分析灵活性称为 researcher degrees of freedom，并给出一组心理学期刊实践建议（例如采集开始前决定终止规则、报告所有实验条件、采用剔除或协变量时同时报告不含该处理的结果）。这不是全国计算机论文法令，不要把六条原样写成理工法定清单，也不要发明「必须采集满 n 人 / n 器件」。迁移时用对等物：仿真何时停止（通信稳态估计已用 Pawlikowski 的预先精度，而不是先看结果再决定跑到「够好」）、哪些随机种子或超参配置被丢掉、哪些负载被剔除。

Gelman 与 Loken，《The garden of forking paths》，未正式发表工作稿，2013-11-14（作者站点 PDF；后续有 2014 年通俗版，此处只作方法提示，不写正式刊出页码）指出：即使没有故意做多路比较，只要分析路径依赖已见到的数据，名义 p 值的解释也会成问题。这支持「不是只有故意 p-hacking 才需要预先声明」，但该稿不是正式期刊版。

## 统计与汇总

- 对多次观测先检查分布、异常和实验单位。确定性计算或单一固定工况可给精确值和条件。存在抽样、测量或运行间波动时，区分描述分散程度的统计量与估计精度的区间。
- 汇总速率先确定分子与分母。两个工作负载分别处理 100 个请求，耗时 1 秒和 10 秒，合并吞吐量为 200/11 ≈ 18.18 请求/秒。给两个负载的速率等权则为 (100 + 10)/2 = 55 请求/秒。前者在等工作量时等于各速率的调和平均，等时长时等于算术平均。正文写明要估计的量与权重。
- 在同一单位上比较两种方法时，依据逐对差值及其不确定度判断差异。两个方法各自的波动范围即使重叠，仍可有一致的配对差。区间过宽时报告观测方向、可支持的范围与仍难区分的效应。
- 不要编造 p 值或在未说明检验与假设时宣称“显著”。需要检验时写清检验名称、假设、样本量和多重比较如何处理。
- 效应量与不确定度（区间、标准误差或文中声明的其他精确度度量）应与点估计一起报告。Lang 与 Altman，*SAMPL Guidelines*（EQUATOR 网络 2013-06-27 文本）是生物医学统计报告指南，可吸收「不要只靠 p 值、报告缺失数据处理、说明多重比较」等原则；文中「通常是 95% 置信区间」不得写成技能默认。通信仿真规程继续把 ε 和置信水平留给作者或刊物，本文件保持同一写法。
- ASA 2016 声明第 3 条：科学结论不应仅仅根据 p 值是否越过某一特定阈值。第 5 条：p 值或统计显著性不度量效应大小，也不度量结果的重要性。允许报告 p 值，但不得只靠它宣称「显著因此重要」或「不显著因此无效」，也不得把 p<0.05 写成技能默认。Wasserstein、Schirm 与 Lazar，*Moving to a World Beyond “p < 0.05”*，《The American Statistician》73(sup1):1–19，2019（打开的是课程站点转载 PDF，不是官方页；特刊内部对「放弃显著性」并无统一立法）只作为反对默认阈值的补充，不得写成禁止使用 p 值。
- 多重比较须披露并处理，但不指定 Bonferroni 或某一种校正为默认。
- 通信仿真、极稀有错误事件、小样本器件测量，各自的误差估计方法不同；没有可靠依据时，如实描述样本与重复次数，不套用其他子领域的经验阈值。通信仿真按 [实验设计](experiment-design.md) 的估计目标选择稳态或终止型规程，不发明错误事件数。机器学习的波动继续报告种子、划分和区间或分布，不套用覆盖因子。

## 测量不确定度（明确物理量）

JCGM 100:2008，*Evaluation of measurement data — Guide to the expression of uncertainty in measurement*（GUM 1995 with minor corrections；2010 勘误版；BIPM 官方免费 PDF）给出 Type A（由观测列的统计分析评定）与 Type B（用其他信息评定）的原则。其原则适用于包括科学与工程研发在内的广泛测量，但主要限制在可被表征为基本上单一值的明确物理量。

- 有重复观测时做 Type A，并报告观测次数 n、标准不确定度与自由度（简单情形为 n−1）。
- n 应大到能可靠估计均值与方差，但不规定最小 n，也不编造「必须测 N 只器件 / 必须重复 N 次」。
- n 较小时不要套用大样本区间；可补充 Type B（仪器、校准、方法文献等）并写明依据。GUM 指出，当 Type A 只基于较少独立观测时，Type B 评定可以同样可靠。Taylor 与 Kuyatt，*Guidelines for Evaluating and Expressing the Uncertainty of NIST Measurement Results*，NIST Technical Note 1297，1994 年版，同向写明：有限次数的 Type A 不一定比有依据的 Type B 更可靠。TN 1297 是 NIST 落实 GUM 的机构指南，适用范围仍是可表征为基本上单一值的测量，不规定最小 n，也不是器件专用规程。
- 覆盖因子 k「通常在 2 到 3」只是注记中的典型范围，必须报告所用的 k，不得写「必须用 k=2」或把 2 到 3 写成技能默认。
- **片上射频或探针测量**（不是所有直流 I–V 或电路仿真）：应报告温度、湿度、探针接触与定位等控制条件；若声称重复性或再现性，须说明重复结构（同一操作者 / 同一仪器的重复，还是换人、换日、换仪器），不要只用一次扫描代替。依据 Orloff 等，NIST 图书章节 *On-wafer measurements of RF nanoelectronic devices*（适用范围是片上射频 / 纳米电子器件的散射参数测量环境）。Randa 等，NIST TN 1939，以及 NIST/SEMATECH 手册 §2.4、§2.4.6 Gauge R&R，只作方法参考：不要把文中的 0.5 K、探针滑移 10–50 µm，或带均匀分布等假设的换算式写成技能默认，也不要编造必测器件数。
- **集成电路封装静风箱 θJA：** 若主张的正是安装在标准测试板上、自然对流（静风箱）下的结到环境热阻比较，应报告该标准意义上的环境控制。依据 JEDEC JESD51-2A（2008-01；本轮打开官方免费 PDF 的 Wayback 快照，现站 403）。目的是标准化环境下封装之间的热性能比较，不是预测应用中的结温。不要把 15°C–30°C 或 ±3°C 写成技能对所有器件测量的默认，也不要发明最小 n。本条不覆盖、也不取代上文 GUM Type A/B、TN 1297 或片上射频/探针条款。
- JESD51-2A 已打开，且仅用于上述静风箱 θJA 比较范围。国家计量技术规范全文公开系统现行站点可以检索到 JJF 1059.1-2012《测量不确定度评定与表示》，状态为现行，发布 2012-12-03，实施 2013-06-03，替代 JJF 1059-1999；官方详情还列出主要起草人（叶德培、赵峰、施昌彦、原遵东、沙定国、周桃庚、陈红）与发布部门（国家质量监督检验检疫总局）。系统帮助要求使用 Adobe Reader 与 FileOpen 插件阅读下载文本；本轮取得的官方 `downPdf` 文件为 FileOpen（`FOPN_foweb`）加密 PDF，无法提取正文，因此**仍不得引用该规范中的公式或最小 n**。不要把「官方可以下载」写成「正文已打开」。GB/T 27418-2017《测量不确定度评定和表示》在国家标准全文公开系统上因采用 ISO/IEC Guide 98-3:2008，官方条目明确「不提供文本阅读服务」，不得当作已打开的替代全文，也不得覆盖上文已编码的 BIPM GUM / TN 1297 / 片上射频 / JESD51-2A 限度。IEC 器件测量标准及其他未打开的 JEDEC 程序（如 JESD51-1）仍不得引用其公式，也不得编造必测器件数。不要把 15–30°C 或 ±3°C 写成通用默认。
- **不要**把通信仿真中的性能估计或机器学习的测试分数改称「按 GUM 计算的测量不确定度」，也不得改称按上述 NIST、JESD51-2A 或未打开规程计算的测量不确定度。通信按稳态或终止型仿真选择估计方法；机器学习继续报告种子、划分和区间或分布。

## 作图与表

制作论文成品时，用原始数据和实际版芯核查结果图、精确比较表与题注。配对、尾部和混合工况的图形选择及单栏缩放示例见[工程论文图表](engineering-figures-tables.md)。

- 图展示趋势和比较，表展示需要精确读出的数值。图表应自明：对象、条件、单位、图例、误差表示都要能独立读懂。
- 坐标轴、起点、截断和比例不得误导（例如用线性轴画应被对称理解的比值、截断纵轴夸大差异）。
- 不要用“最高提升 49%”概括一组很不均匀的结果，除非同时给出分布或逐项结果。
- 分析、仿真、实测曲线若画在同一图中，必须标明来源，假设不同时不能画成互相“验证”却不解释残差。
- 图号、表号、正文引用和题注一致。使用校刊规定的编号形式，如“图 2”或“图 3-2”，使重新排版后仍能准确定位。
- Rougier、Droettboom、Bourne，《Ten Simple Rules for Better Figures》，《PLoS Comput Biol》10(9):e1003833，2014，可补充：图要有一个清楚的信息；图注让图尽量自明；编码在灰度或色觉差异下仍可分。不要把该文十条整份写入，也不要把禁止三维柱图一类偏好写成法令。

## 解释结果

- 先报告得到了什么，再解释可能原因；原因是推断，要与设计中的机制对应，避免无依据的故事。
- 负面结果和权衡要写。它们常常比再堆一个得意指标更有价值，也能避免过度承诺。不要写成必须设 Limitations 专节或必须单开一章负结果。
- 结论强度回到三档主张：直书 / 限定范围 / 不主张。
- 可复现不等于数字比特级相同；独立复现应在声明容差内仍然支撑主要主张。

## 缺数据时怎么做

先交代缺失机制的合理假设，再选择方法并报告。Rubin，*Inference and missing data*，*Biometrika* 63(3):581–592，1976，第 582 页给出 “missing at random” 与 “observed at random” 的形式定义。后来的 MCAR、MAR、MNAR 可按缺失概率依赖哪些信息来区分。MCAR 假设缺失机制独立于观测值和缺失值。MAR 允许依赖已观测的信息，给定这些信息后缺失概率与缺失值无关。MNAR 下即使控制已观测信息，缺失概率仍依赖未观测值。各组缺失比例接近不能证明 MCAR，单凭已观测数据通常无法区分 MAR 和 MNAR。应根据数据产生过程解释假设，并在影响结论时做敏感性分析。[van Buuren，第二版 §2.2.4](https://stefvanbuuren.name/fimd/sec-idconcepts.html)

- 列出缺的是哪一次运行、哪一个条件、哪一张表，并说明对缺失机制的合理假设（MCAR / MAR / MNAR）。
- 给出可执行的补测计划，或建议收窄正文中的句子。
- **完整案例（列表删除）不是普遍禁止，也不是普遍安全。** van Buuren §1.3.1：若数据为 MCAR，对均值、方差和回归系数的估计可无偏，标准误对缩小后的子样本是正确的，但相对全部可用数据往往更大（低效）；若不是 MCAR，则可能严重偏倚。Schafer 与 Graham（约第 155–156 页，「Properties of case deletion」）写：案例删除一般只在 MCAR 下成立；少数情形下对某些参数在 MAR 下也可以有效，但这一结果不自动推广；非 MCAR 时完整案例可能无法代表总体。只在丢掉很小一部分样本、并且检查过被删案例是否过分有影响时，这一做法才比较简单可用。不要写「缺失不到 5% 就可以列表删除」。
- **多重插补或似然方法是 MAR 下常用的原则性做法，不是唯一合法选择。** 不要写成「必须用多重插补」或必须用 MICE。van Buuren 写，多重插补不是简单的技术补丁，需要判断缺失机制、设定插补模型并检查；MICE 并非在一切条件下都有事先保证的收敛。Schafer 与 Graham 开篇即写「no single procedure that is technically correct in every situation」。
- 不得用插值、生成式“补全”或邻组数字填进结果表冒充观测。依据包括本条既有禁令、SAMPL「必须报告缺失数据如何处理」，以及 0812「不选择性使用实验和观测数据」。不要声称 0812 或 SAMPL 已点名生成式模型。
- 若使用插补，必须把方法、假设和哪一格不是原始观测写清楚，并且不得在结果表里把插补值排成与实测无法区分的「观测」。

## 计算记录

Sandve、Nekrutenko、Taylor、Hovig，《Ten Simple Rules for Reproducible Computational Research》，《PLoS Comput Biol》9(10):e1003285，2013，以及 Wilson 等，《Good enough practices in scientific computing》，《PLoS Comput Biol》13(6):e1005510，2017，支持保留脚本、参数，并区分原始数据与派生数据；记录计算步骤，避免手工改数。Wilson 等把自己定位为「够用」的实践，不是最高标准清单。可建议尽可能保留可复核的脚本和参数；不要把「必须公开全部代码」写成学位条件。学校或刊物另有要求时，再执行该要求。
